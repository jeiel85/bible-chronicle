# 01. 제품 요구사항 명세 (PRD)

## 1. 비전 및 대상

**비전**: 고대 근동의 문명 변화와 성경 정경의 이야기를 교차 탐험하면서, 각 사건을 성경 본문 및 역사 자료와 연결하는 '학습 우선 역사 체험'을 제공한다.

- 1차 대상: 교회 교육 교사, 중고등부 및 성인 성경 학습자
- 2차 대상: 성경 배경과 고대 역사를 탐구하는 일반 독자
- 초등 저학년의 경우 폭력·전쟁 묘사를 완화하는 보호자/교사 설정 필요
- 역사 연구 결과와 종교적 믿음은 별도 층위로 제공하며 이용자가 확인할 수 있어야 함
- 한국어 UI 기본, i18n 키/원문 인용 어댑터로 확장

## 2. 제품의 비가역 규칙

1. **정경 고정(Canonical invariance)**: 성경 원문이 명시한 사건의 결과는 바뀌지 않는다.
2. **제한적 선택(Convergent agency)**: 선택은 사용자의 관찰 경로·자료 열람·개인 노트·지식 해제 등에만 영향. 다른 선택도 동일한 역사적 결말로 합류한다.
3. **저자/독자 구분**: 가상 인물·가상 대화는 전부 창작 재구성으로 표시. 원문에 없는 인물의 발언을 성경 인용처럼 보이지 않게 한다.
4. **본문 우선**: 사건의 핵심 주장과 선택 가능한 표현은 성경 위치로 추적해야 한다.
5. **가설 표시**: 지도·연표·비교 자료는 별도 외부 근거 및 불확실성 정보 필수.
6. **전체 성경 포함**: 역사 서사뿐 아니라 시가, 율법, 예언, 서신, 묵시 문학의 성격에 맞는 독해 콘텐츠로 66권 모두를 수록한다.
7. **동일 사건의 복수 증언**: 복음서/열왕기와 역대기 등 병행본문을 정규화된 공통 사건에 연결하고 본문별 관점을 삭제하지 않는다.

## 3. 플레이 방식

### A. 관찰자(기본)
- 역사 연대표 → 시대/지리 선택 → 정경 사건 카드 → 유물/사료 → 복습
- 시대의 동시대 사건을 나란히 비교할 수 있으나, 아직 공개되지 않은 시대의 지도를 확정 정보처럼 보여주지 않는다.
- 교사용 수업 모드에서 설명/질문/지도 중심 보기 지원.

### B. 성경 인물 체험
- 내러티브 카메라 및 정보 표시를 인물 관점으로 변경.
- 인물의 내심, 추가 대사, 행동에 대한 가상의 선택은 본문 사실과 구분하여 표시.
- '골리앗을 이기지 않는다', '왕국 분열을 막는다' 같은 대체 역사는 제공하지 않음.
- 성경에 행위가 명시되어 있는 선택은 역사적 사실을 바꿀 수 없으므로 플레이 가능한 분기 대신 텍스트 독해·확인 활동으로 처리.

### C. 가상 목격자
- 도시 장면에서 인물을 만나 당시 생활사(식량/교역/군사/종교)의 **검증된 일반 배경**을 탐색.
- 원문에 없는 인물을 사실 인물로 표현하지 않으며, 사건의 당사자로 사건 인과를 변경하지 않는다.
- 사용자의 선택에 따라 장면의 순서·카메라 초점·교사용 질문만 변화.

## 4. 행동과 보상 (전쟁/정복을 목표로 삼지 않음)

- 학습 루프: 시대 지도 진입 → 사건 질문 → 본문 확인 → 문명 변화 지도 관찰 → 두 개 이상의 근거 비교 → 학습 기록 → 다음 핵심 장면.
- 자원: `knowledge` (자료 확인), `context` (배경 주제 탐색), `reflection` (개인 메모). 전투/물자 자원으로 사건 결과 변경 금지.
- 완료: 책 전체 완독 / 장별 학습 확인 / 시대 타임라인 탐험 / 사건별 사료 검증 확인.
- 점수는 학습 추적용(정답 재시도, 출처 찾기, 문화 이해). 구원·은혜·신앙적 진정성에 게임 점수를 매기지 않는다.

## 5. 대표 체험 예시: 라기스 공성전

1. 화면 상단: '유다 왕국 / 앗수르 제국의 팽창 / 기원전 701년(외부 사료의 사건 연대)' 표시.
2. 지도: 유다 영역의 라기스와 예루살렘. 국경 범위는 시대/근거 없으면 표시하지 않음.
3. 정경: 열왕기하 18장 및 이사야 36장의 관련 구절로 이동.
4. 주목 사건: 라기스 공격 부조를 '외부 사료'로 표시하고 대조 설명.
5. 선택: '공성 무기 살펴보기' / '주민 생활에 미친 영향 읽기' / '당대 제국 지도를 보기'.
6. 세 선택은 모두 동일한 `siege_lachish_701` 정경 결과에 합류. 발견한 근거/메모만 다름.

## 6. 명시적으로 하지 않을 것

- 정경 결말을 바꾸는 외교, 건국, 침략, 왕의 선택, 시간 여행
- 가공 국가들의 고대 지도를 실제 고대 국경으로 위장
- 성경에 없는 '숨겨진 사실'을 역사 지식처럼 확정해 제시
- 외부 사료가 예수의 신적 정체나 기적의 신학적 의미 자체를 검증했다고 주장하는 장치
- 게임 달성을 위해 성경 본문 해석을 하나로 강제하는 선전형 퀴즈

## 7. 성공 지표 (목표치 아님, 출시 후 측정 정의)

- 66권 전권을 참조하는 장 색인 누락 0개
- 공개 콘텐츠에서 출처 필드 누락 0개
- 역사 사실 미검증 주장 0개 공개
- 선택에 의한 `canonicalOutcomeId` 변조 테스트 통과 100%
- 세로/가로/PC 3종 화면 유효성 및 접근성 검사 통과
- 로컬 오프라인 모드 핵심 학습 진행 가능
