# 02. 66권 전범위 콘텐츠 모델

## 1. 성경은 '한 줄 타임라인'이면서 '문학 작품의 집합'이다

성경의 핵심 서사에는 계보/연속성이 있지만 66권의 집필 시대·문학 장르·행위 시기는 하나의 단일 연대순 줄로 환원되지 않는다. 예를 들어 시편, 잠언, 레위기의 율법, 바울 서신, 계시록의 환상은 지도를 따라 이동하는 사건과는 다른 독해 방식이 필요하다.

**두 개의 탐색축** 제공:
- `canonical_order`: 창세기 → 요한계시록; 66권 모든 장 포함.
- `historical_context`: 시대 사건 중심이며, 날짜 미상/시대 추정/동시 발생/후대 회고를 지원.

`historical_context`는 특정 문학 작품을 억지로 정확한 해에 고정하지 않는다. `writtenAt`(저술 시기)와 `depictedAt`(서술상 사건 시기)도 별도 데이터다.

## 2. 3계층 콘텐츠

| 수준 | 단위 | 필수 필드 | 완성 조건 |
|---|---|---|---|
| 성경 텍스트 커버리지 | 성경 66권 × 1,189장 | 책/장/장르/학습 상태 | 모든 장에 내용/근거/읽기 경로 있음 |
| 문학·주제 단위 | 율법/시가/비유/예언/서신의 단락 | 범위/장르/핵심 질문/상호 참조 | 빠진 장 없이 단락이 커버 |
| 사건·지도 단위 | 정경 사건 / 역사 외부 사건 / 서사 화면 | 구절, 연대, 장소, 근거, 연출 | 해당 사항 있을 때 검증 후 공개 |

`data/chapter_index.json`는 현재 **색인만 생성**하며 수록된 해설·원문 콘텐츠를 의미하지 않는다. 사건 중심 콘텐츠만으로는 66권 전부를 담을 수 없으므로 장별 커버리지 검사가 별도로 필요하다.

## 3. 주요 시대·서사 아크 (학습용 구분, 연대 확정표 아님)

1. 창조·타락·홍수·바벨 (창 1–11; 역사 연대/지도 미정)
2. 족장과 가족 이야기 (창 12–50)
3. 출애굽·광야·시내산·율법 (출–신; 절대연대 논쟁)
4. 가나안 정착 서사와 사사 시대 (수–룻)
5. 사울·다윗·솔로몬의 왕국 (삼상–왕상 11, 대상–대하 9)
6. 이스라엘·유다 왕국과 선지자들 (왕상 12–왕하 17, 역대기, 일부 예언서)
7. 앗수르 확장과 유다 위기 (왕하 18–20, 사 36–39)
8. 바벨론 침공과 유다 왕국 종말 (왕하 24–25, 렘, 대하 36)
9. 포로와 회복, 제국 변화 (에스라·느헤미야·에스더·다니엘의 배경과 병행)
10. 시가·지혜·율법/신학 주제 (관련 장르별 모듈; 시대에 억지 고정 금지)
11. 예수의 탄생과 초기 사역 (4복음서 병행)
12. 예수의 공생애·가르침·수난·부활 (4복음서 병행)
13. 초기 교회와 바울의 선교 (사도행전, 서신서 병행)
14. 서신과 공동체의 가르침 (로마서–유다서; 작성 맥락 이견 표시)
15. 계시록의 묵시·예배·완성의 비전 (계 1–22; 미래 연도와 지리 국경으로 확정 표기 금지)

## 4. 정경 사건(CanonicalEvent)과 설명(Interpretation) 분리

- `CanonPassage` : `bookId, chapterStart, verseStart?, chapterEnd, verseEnd?` (구절은 데이터 공급 계약 후 표시)
- `CanonicalEvent` : 안정 ID, 제목, 관련 본문 다대다, 설명문, `canonicalOutcomeId` (수정/선택 불가)
- `Interpretation` : 교단/학파/해석명/근거/반론/검토자와 버전
- `HistoricalClaim` : 참조 출처, 주장 범위, 주장 상태와 학술 이견
- `Scene` : 사건별 화면·카메라·일러스트·사운드·선택
- `LiteraryUnit` : 본문 단락, 문학 유형, 문맥 학습 (내러티브 이벤트 없음 가능)
- `ParallelPassage` : 동일 사건 혹은 유사한 주제의 본문 다대다 관계

예: 동일 주제를 사무엘하와 역대상에 각각 등장한다고 해서 두 사건으로 세지 않고, 한 정경 사건의 두 병행증언으로 관리한다. 사건과 관계 없는 신학·묵상 주제는 `LiteraryUnit`로 관리한다.

## 5. 중요 편집 방침

- 정경 순서와 장/절 범위는 66권 개신교 판본에서 검증; 다른 정경(제2경전 등)은 후속 확장 콘텐츠 팩으로 분리.
- 원문 제공 라이선스를 확보하지 않으면 '본문 연결 + 자체 작성 요약 + 사용 허용된 구절'로 대응.
- 저자·저술연대·사본차이·사건연대는 별도 `assertion` 모델로 관리하고 견해 다수를 병렬로 담는다.
- 지역 명칭(유다/이스라엘/사마리아 등)은 당시 정권·행정 구분에 맞게 표기한다.
- 동일 사건의 시간 순서가 확정되지 않으면 순서를 강제하지 않는다: `before`, `after`, `overlaps`, `unordered`, `unknown`.
- 서로 다른 복음서 연대/배열 및 숫자/이름 차이가 있으면 편집으로 소거하지 않고 출처별 주석으로 공개한다.

## 6. 커버리지 측정과 공개 게이트

- Coverage = `authored && canonical_coverage_complete && reviewed` 장의 수 / 1,189.
- `draft`는 개발 미리보기로는 가능하나 교사 수업 기본 경로에 노출하지 않는다.
- 각 권은 최소 `bookSummary`, `literaryUnits`, `chapterCoverage`를 충족해야 공개 상태.
- 성경 본문에 지리적 등장 장소가 없으면 지도 없음이 정상이며, 임의 지도 장면을 채우지 않는다.
- `All 66 Books` 화면에서 `편집 전`, `초안`, `성경 검수`, `사료 검수`, `공개`를 투명하게 표시.

## 7. 예외 처리

- 창세기 원역사: 현대 지리 좌표 및 절대 연대 추정 고정하지 않음.
- 욥기: 서사 배경·저술연대를 혼동하지 않음.
- 시편/잠언: '역사 이벤트'가 아니라 시/지혜 문학 독해 카드와 주제 연결.
- 요엘서/오바댜서: 연대 이견이 있으면 단일 확정 기원전 숫자로 강제하지 않음.
- 요한계시록: 상징·환상과 역사적으로 확인된 도시·정치세력을 같은 타입으로 표현하지 않음.
- 신학적 진술(하나님의 말씀, 기적)은 성경 서술로 소개하고 자연과학적 검증 항목과 분리.
