# 04. UI/UX — 문명형 역사 탐험과 반응형 화면

## 디자인 원칙

- '문명 같은 감성'은 국가의 영토를 직접 재구축하는 게임이 아니라, **지도→시대→사건→유물→성경 본문**의 정보 깊이에서 나온다.
- 화면 상단에는 시대/사건/시점, 좌측에는 책·연대표, 중심은 지도/일러스트, 우측은 본문/사료가 기본.
- 세로 모드에서 모든 요소를 무리해서 압축하지 않고 동일 데이터의 UI 배열만 전환한다.
- 모바일 회전 시 상태 보존: `eventId`, `sceneId`, `choiceSelections`, `map.camera`, `scrollAnchor`, `openPanels` 유지.

## 레이아웃 분기

| 모드 | 기준 | 배치 |
|---|---|---|
| 모바일 세로 | 좁은 너비 (예: < 600 CSS px) | 상단 시대 헤더/일러스트 → 본문 → 지도 접이식 → 하단 고정 이동 탭 |
| 모바일 가로 | 가로이면서 제한된 높이 | 지도 또는 사건 이미지 55% / 이야기 45%; 패널 회전 가능 |
| 태블릿 | 약 600–1023 CSS px | 지도로 시작, 보조 드로어, 2단 스플릿 |
| PC | 약 1024 CSS px 이상 | 3영역: 시대 탐색/지도+이미지/사건 패널; 크기 조정 |

참고: px 범위는 고정 기기 분류가 아니라 CSS 컨테이너 기반 출발값. 브라우저 크기, 접힘 폰, 200% 텍스트 확대 시 레이아웃 자동 축소.

## 화면 상세 규칙

1. **역사/성경/연출의 시각적 구분**: 내용 타입 텍스트 칩+아이콘+보조색. 색상만으로 구분하지 않는다.
2. **지도 범례**: 실선=출처 확인된 지리 정보; 점선/반투명=재구성; 회색 물음표=정확한 위치 모름. 도형이 실선이어도 역사적 영토 경계의 신뢰도를 보장하지 않으므로 `데이터 근거 보기`를 제공.
3. **연대표**: 불확실한 사건은 기간 막대/대략 날짜, 정확한 시간 정보 없는 사건은 '연대 미상' 트랙.
4. **일러스트**: '역사 자료 사진'과 '상상 재현 삽화' 썸네일/문구/크레딧 분리.
5. **선택**: 신앙의 우열을 결정하거나 성경 사건을 재작성하는 분기 금지. 선택 결과는 '이해한 배경 정보'로만 저장.
6. **퀴즈**: 풀이 후 항상 근거 본문·사료로 되돌아갈 수 있음. 해석 논쟁 사항은 단일 정답 문제 금지.
7. **교사용 모드**: 학습 질문/사료/핵심 본문으로 구성된 발표 전용 화면, 화면 잠금, 질문 순서 지정; 계정 없이 기기에 저장.

## 회전/리사이즈/입력 장치

- 모바일 자동 회전은 OS 회전 설정에 따름. 웹은 브라우저가 지원하는 범위에서만 회전 요청; 실패해도 세로 UI 유지.
- 가로·세로 강제 잠금 필요하면 별도 앱 래퍼를 통해 OS별 정책 검토; 브라우저 PWA는 플랫폼 제약이 있음.
- 포인터(마우스)/터치/키보드/스크린리더 사용 가능.
- 지도 제스처는 2손가락 탐색과 보조 +/- 버튼 제공; 지도 때문에 페이지 스크롤이 막히지 않게 처리.
- 인터랙티브 컨트롤 최소 터치 크기 44×44 CSS px 목표, 고대 지명 키보드 리스트 대체 제공.
- `prefers-reduced-motion`이면 줌/카메라 이동/영상 자동재생 억제.
- 내러티브 글자 크기 및 대비 변경, 본문 출처 고지, 폭력적 묘사 축소 옵션.

## 주요 화면/컴포넌트 목록

- `ChronicleHome`, `CanonicalBookShelf`, `EpochTimeline`, `EpochMap`, `FactionInspector`, `PlaceInspector`, `EventReader`, `CanonPassageSheet`, `HistoricalEvidenceDrawer`, `ParallelAccounts`, `CharacterView`, `WitnessView`, `SceneChoiceList`, `LiteraryReading`, `QuizCard`, `TeacherPresentation`, `LearningProgress`, `SourceLicensePanel`, `OfflinePackManager`.

## 지도에서의 문명식 연출

- 시대별 제국 등장·퇴장 시 애니메이션 오버레이, 실제 시대/경계 불명확성 표기 유지.
- 세력 카드: 제국·도시·정권·권력자·조공관계/갈등관계를 **사료 기반 관계 타입**으로 표현.
- 사건 이미지의 구도는 수평선이 낮은 파노라마 형태; 도시·군대 규모 임의 사실화 금지.
- 사료가 없는 장면에서 '실제 재현'이라는 카피를 사용하지 않는다.
