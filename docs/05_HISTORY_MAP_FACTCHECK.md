# 05. 역사 검증 프로토콜과 고대 지도

## 1. '팩트체크'의 의미를 구체적으로 정의

'성경에 기록되었다'와 '외부 사료로 입증되었다'는 서로 다른 종류의 주장이며, 외부 검증이 안 된 사건은 역사 부정 판정이 아니다. 한 문단에 여러 역사 주장이 있으면 문장을 쪼개서 각각 원장에 기록한다.

| 코드 | 설명 | UI 문구 |
|---|---|---|
| `biblical_text` | 성경 구절에 직접 서술된 사건/발언 | 성경 기록 |
| `external_primary` | 비문·점토판·당대 사료 등에 직접 언급된 한정된 주장 | 외부 1차 사료 확인 |
| `external_secondary` | 출처 있는 학술 연구·역사 사전의 해석 | 학술 연구에 근거 |
| `scholarly_debate` | 주요 견해가 갈리고 날짜·위치·해석에 이견 | 학술적 이견 |
| `unverified` | 현재 이 패키지에서 자료 검증을 마치지 못함 | 확인 필요 |
| `fictional_reconstruction` | 직접 기록되지 않은 배경/상황 연출 | 창작적 재구성 |
| `theological_claim` | 신앙·초자연적 해석, 과학적 검증과 다른 인식 층위 | 성경의 신학적 서술 |

### 금지 문구

- '유물이 발견되어 모든 성경 기록이 진실로 증명됨'
- '기록이 없으므로 해당 성경 사건은 일어나지 않았음'
- '학계가 이미 확정한 출애굽 이동 경로'
- '현대 국가 국경과 같은 정확한 다윗 시대 영토'

## 2. 사실 검증 7단계

1. 원문 출전 등록: 책·장·절·번역판 사용권 구분.
2. 검증 대상이 되는 원자적 명제 작성 (`A가 B를 공격했다`, `시기는 약 x`).
3. 원전 유형 식별: 유물/비문, 고대 문헌, 고고학 보고서, 후대 역사서, 현대 연구.
4. 자료가 직접 말하는 것과 추론을 구별: 원전이 '전쟁이 있었다'고 말할 때 '성경에 나온 모든 세부 행동 확인'으로 확대 금지.
5. 날짜/지명/왕조/번역 해석에서 학설이 다른지 독립 문헌으로 점검.
6. 별도 검토자 승인: 성경 원문 검토, 역사/고고학 검토, 지도 검토, 라이선스 검토.
7. 공개 후 수정 가능하도록 `checkedAt`, `revision`, `supersedes`, `changeLog` 보관.

대조 출처에 접근할 수 없거나 필요한 본문이 부분 공개면 **원전 검증 미완료**로 표시하고 '완전 검증' 상태를 주지 않는다.

## 3. 본 패키지에서 실제 확인한 사례

### 외부 사료 사례 A: 기원전 701년 라기스

- 성경 관련: 왕하 18:14, 18:17; 사 36:2
- 외부 사료: 영국박물관의 라기스 공격/포로 행렬 부조; 박물관은 라기스가 701 BC에 산헤립에 의해 함락됐다고 설명.
- 확인 가능한 범위: 앗수르 왕 산헤립의 라기스 공성전과 당시의 군사·포로 묘사.
- 확인할 수 없는 범위: 부조만으로 열왕기하 기록의 모든 대화와 사건 결과가 독립 증명되지는 않음.
- 출처: https://www.britishmuseum.org/collection/galleries/assyria-lion-hunts 및 https://www.britishmuseum.org/collection/object/W_1856-0909-14_2

### 외부 사료 사례 B: 기원전 597년 예루살렘 원정

- 성경 관련: 왕하 24:10–17
- 외부 사료: 영국박물관 소장 바벨론 연대기 점토판(BM 21946): 느부갓네살의 597 BC 예루살렘 원정을 기록.
- 확인 가능한 범위: 바벨론군이 이 시기에 예루살렘을 공격했다는 독립 기록의 존재.
- 확인할 수 없는 범위: 후대 기원전 587/586년의 성전 파괴까지 이 단일 연대기 판이 직접 기록했다고 확대 해석하면 안 됨.
- 출처: https://www.britishmuseum.org/collection/object/W_1896-0409-51

### 외부 사료 사례 C: 다윗 왕조 명칭

- 성경 관련: 삼하 7장, 왕상 왕조 서술
- 외부 사료: 텔 단 비문(기원전 9세기), '다윗의 집'으로 읽는 표현.
- 확인 가능한 범위: 후대 비문에서 다윗 왕조 명칭 사용 증거. 실제 다윗의 개인 행적 전체의 증거는 아님.
- 출처: https://thejewishmuseum.org/exhibitions/tel-dan-stele/

### 학술적 이견 사례 D: 출애굽

- 성경 관련: 출애굽기 1–15장
- 쟁점: 사건의 규모, 시기, 이집트 밖 이동 경로 등에 직접 확인되는 당대 기록과 고고학적 근거가 부족하며 학자 간 해석 차이가 큼.
- 서로 다른 연구 관점을 검토할 입문 자료:
  - J. K. Hoffmeier, *Israel in Egypt* (Oxford University Press, 1999): https://doi.org/10.1093/acprof:oso/9780195130881.001.0001
  - *Did I Not Bring Israel Out of Egypt?* (Penn State University Press, 2016): https://doi.org/10.5325/j.ctv1bxgxxt
- 구현: 성경 서사 체험은 가능하되 고정된 출애굽 경로와 연대표를 '검증 완료'로 표기하지 않는다.

## 4. 지도 구조

### A. 기본 지형
- Natural Earth 지형/해안선: 퍼블릭 도메인. **오늘날의 축척/지형 데이터**이지 기원전 국가 경계가 아니다.
- 출처/이용약관: https://www.naturalearthdata.com/about/terms-of-use/
- 현대 국경 레이어는 고대 지도에서 기본 숨김.

### B. 고대 지명
- Pleiades 고대 지명 사전: 지명·대체명·좌표·링크를 참고, CC BY 3.0 귀속 규정과 개별 데이터 출처 확인.
- 출처: https://pleiades.stoa.org/participate 및 https://pleiades.stoa.org/downloads
- Pleiades가 모든 성경 지명, 위치, 시대 국경을 직접 제공하는 것은 아님.

### C. 영토·세력관계

```ts
type HistoricalGeometry = {
  entityId: string;
  geometry: GeoJSON.Geometry | null;
  validFrom?: number; // 천문학적 연도
  validTo?: number;
  certainty: 'site'|'approximate'|'contested'|'unknown';
  historicalContextIds: string[];
  sourceIds: string[];
  geometryMethod: 'source_traced'|'editorial_estimate'|'not_mapped';
  label: string;
};
```

- 경계 재구성은 각 시대별로 독립 검수. 현존하는 학술 도판을 단순 트레이싱하거나 그대로 복제하려면 원자료 재사용 허락/라이선스 확인.
- 미상 국경은 `geometry = null`, 지도 레이어 표시를 하지 않음.
- 선형 애니메이션으로 확정되지 않은 두 지리적 경계를 보간하는 기능 금지.
- 사료가 입증한 수도/거점과 정치 지배범위 추정은 다른 레이어.
- 시대가 다른 '가나안', '이스라엘', '유다', '팔레스타인' 명칭 혼용 금지.

### D. 기간별 레이어/시각화

| 시대 아크 | 주요 계층 후보 | 검증/불확실성 주의 |
|---|---|---|
| 족장 전승 | 메소포타미아, 하란, 가나안 지명 | 인물 이동 경로의 정확 위치·연대 미확정 |
| 출애굽/광야 | 이집트·시내 지역 후보 지명 | 경로를 확정선으로 표시 금지 |
| 사사·왕국 | 도시 위치·정치 중심지 | 국경/도시 지배 범위 재구성 필요 |
| 분열 왕국 | 북이스라엘·유다 중심지 | 시대별 지배 범위가 유동적 |
| 앗수르·바벨론 | 제국 거점·원정 대상·포로 이동 | 원정 연대와 구체 경로 분리 |
| 헬라·로마 | 제국·행정구역·교통로 | 복음서 당시 행정체제에 맞춘 지도 |
| 초대 교회 | 바울 선교 여정에 언급된 지역 | 정확 경로/항해 구간은 근거에 따라 표시 |
| 요한계시록 | 일곱 교회의 역사적 도시 지점 | 묵시적 이미지·상징을 물리적 영토로 표시 금지 |

## 5. 근거 레코드의 필수 필드

```json
{
  "claimId": "CLAIM-001",
  "assertion": "라기스는 기원전 701년 앗수르 왕 산헤립의 공격을 받았다",
  "claimScope": "공성전 및 시기",
  "classification": "external_primary",
  "evidence": [
    {"url":"https://www.britishmuseum.org/collection/galleries/assyria-lion-hunts", "type":"museum_catalog", "supports":"박물관 전시실 설명이 701 BC 함락을 명시"}
  ],
  "verificationStatus": "source_checked_scope_limited",
  "checkedAt": "2026-10-12",
  "limitations": "모든 성경 대화나 신학적 내용에 대한 독립 증명은 아님"
}
```

이 패키지에 포함된 `data/historical_claims.json`는 검증 **샘플만** 포함한다. 모든 사건의 팩트체크 완료를 의미하지 않는다.

## 6. 자료 관리 리스크

- 역사 연표는 종교적 전통, 학문 분야, 연호 체계에 따라 다르므로 `confidence`와 의견 그룹을 유지.
- 성경 등장 인물과 역사적 실재 인물 일치는 인명만으로 자동 확정 금지.
- 검색 결과/커뮤니티 글은 초벌 조사에만 활용; 1차 사료/박물관/학술 출판으로 확인.
- 유물 자체의 촬영 사진에도 별도 저작권이 있을 수 있으므로, 유물 기록 URL과 실제 사용 가능한 이미지 라이선스는 다른 항목.
