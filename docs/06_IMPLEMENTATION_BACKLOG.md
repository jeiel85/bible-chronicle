# 06. 즉시 개발 착수용 구현 백로그

## 의존성 개요

`E0 콘텐츠 계약 고정` → `E1 정경 색인` + `E2 시점/선택 엔진` + `E3 UI shell` → `E4 지도 계층` → `E5 편집/검수 파이프라인` → `E6 시대별 집필/자료` → `E7 오프라인 QA/배포`

## E0. 프로젝트 기반 (P0)

- [ ] MONO-001 Vite/React/TypeScript strict 모드 템플릿 구성; ESLint/formatter/TS build
- [ ] MONO-002 `schemas/event.schema.json` 빌드 검증 연결; 실패 시 PR 차단
- [ ] MONO-003 정적 콘텐츠 매니페스트/버전/해시 규약 적용
- [ ] MONO-004 배포 환경(GitHub Pages 등) base path 및 SPA fallback 검증
- [ ] MONO-005 66권/1,189장 스캔 검사 파이프라인 실행

**수용 기준:** PR에서 1장 누락하거나 사건 결말을 변경하는 선택을 추가하면 CI가 실패할 것.

## E1. 정경 및 문학 단위 (P0)

- [ ] BIBLE-001 66권/장 목록 및 각 책의 장르 서랍 생성
- [ ] BIBLE-002 본문 레퍼런스 라우팅 (`/bible/:book/:chapter`, 선택적 절)
- [ ] BIBLE-003 문학 장르별 템플릿 7종 (서사/율법/시·지혜/예언/복음서/서신/묵시)
- [ ] BIBLE-004 병행본문 다대다 구조와 비교 화면
- [ ] BIBLE-005 모든 장의 저술/검수/공개 상태 대시보드
- [ ] BIBLE-006 성경 원문 이용권 없는 경우 본문 출처 링크/자체 서술 방식 적용

**수용 기준:** 장르와 관계없이 모든 장 화면에 접근 가능하되 미집필은 '미집필'로 정직하게 안내.

## E2. 스토리/선택 엔진 (P0)

- [ ] STORY-001 `canonicalOutcomeId`를 `SceneChoice`로 변경 불가한 타입/런타임 규칙 구현
- [ ] STORY-002 선택별 카메라/학습 카드/노트만 다르게 렌더
- [ ] STORY-003 동일 사건의 세 모드 간 진행도 공유
- [ ] STORY-004 씬 상태 local persistence/복구 및 우회 클릭 방지
- [ ] STORY-005 성경에서 직접 기록한 사실과 연출 문구를 화면 구별

**수용 기준:** 동일 사건의 모든 선택 패스에서 결과 ID는 같고 개인 탐색 로그만 다를 것.

## E3. 반응형 UI (P0)

- [ ] UI-001 portrait/landscape/desktop 3개의 shell 구현
- [ ] UI-002 연표/이벤트/책장/학습 진행/사료 패널 구현
- [ ] UI-003 디바이스 회전 시 이벤트/스크롤/지도 카메라 보존
- [ ] UI-004 키보드/스크린리더/200% 확대 접근성 테스트
- [ ] UI-005 교사용 발표 보기 및 폭력 묘사 완화 옵션

**수용 기준:** 모바일 회전 후 현재 사건의 선택 상태 손실 없음.

## E4. 시대별 지도 (P0~P1)

- [ ] MAP-001 MapLibre + 퍼블릭 도메인 지형 계층을 묶은 초기 지도
- [ ] MAP-002 고대 지명 ID/시대/출처/이름 변형/확실성 필드 구현
- [ ] MAP-003 `null` 위치/국경의 렌더링 금지 테스트
- [ ] MAP-004 시기별 도시/국가/사료 계층 + 범례
- [ ] MAP-005 세력 카드 (시대/관계/근거) 및 지도 클릭/키보드 대체
- [ ] MAP-006 현재 사건 지도→다음 사건 카메라 이동 (reduced motion 지원)

**수용 기준:** 출처 없는 제국 국경이나 추정 경로를 '검증 완료'처럼 표시하지 않음.

## E5. 사료/콘텐츠 관리 (P0)

- [ ] EDIT-001 저작/검토/출처/라이선스 필드를 강제하는 파일 기반 CMS
- [ ] EDIT-002 주장별 증거 및 반론 연결
- [ ] EDIT-003 공개 등급 변경 이력 및 두 단계 검수(본문/역사)
- [ ] EDIT-004 시대/지리 검수자 확인 없으면 지도 배포 차단
- [ ] EDIT-005 외부 URL 유효성 체크, 링크 부패 감지, 인용 쿼리 로그
- [ ] EDIT-006 AI 생성 이미지/요약 공개 전에 사람이 성경/문화/복식·의상 검토

**수용 기준:** 역사 연대가 표기된 공개 카드마다 날짜·근거·한계 데이터 존재.

## E6. 콘텐츠 제작을 별도 핵심 작업으로 관리 (P0, 병렬)

- [ ] CONTENT-001 성경 66권 학습 원고 템플릿 및 장 단위 집필/검토
- [ ] CONTENT-002 사건/주제 단락 세그먼트와 누락 제로 장 커버리지 검사
- [ ] CONTENT-003 핵심 서사 아크 1개를 완성(창세기 1–11 시범은 역사 지도 최소화)
- [ ] CONTENT-004 검증 외부 사료 중심 아크 1개 완성(라기스–예루살렘–포로의 시대)
- [ ] CONTENT-005 복음서 4권의 병행본문 시나리오 제작
- [ ] CONTENT-006 율법/시가/예언/서신/계시록 독립 학습 UX 검증
- [ ] CONTENT-007 전체 장 커버리지를 검토 완료로 올릴 때까지 순차 집필

**중요:** '프로그램 코딩 완료'와 '66권 본문·학습 자료 모두 준비'는 별도 마일스톤. 콘텐츠 집필은 자동 생성본만으로 끝낼 수 없음.

## 단계별 배포 게이트

| 릴리스 | 기술 준비물 | 콘텐츠 준비물 | 대외 표기 |
|---|---|---|---|
| Developer preview | 정경 색인, 읽기, 지도/이벤트 엔진 | 샘플 사건 1~3개 + 전체 권 미집필 표시 | 기술 시연 |
| Educational pilot | 교사용 UI, 오프라인, 사실/권리 검증 | 선택한 한 시대/아크 100% 인력 검수 | 시범 교보재 |
| Full Bible v1 | 모든 66권 장 커버리지, 장르 UI, 안전/성능 검증 | **1,189장 전체 서술·검수 완료** | 전권 교보재 |

데이터베이스 규모, 이미지 제작량, 공수는 각 장의 단락 분할과 그림 밀도가 결정되지 않았으므로 현재 확정 수치로 제시하지 않는다.
