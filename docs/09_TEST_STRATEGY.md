# 09. QA / 콘텐츠 일관성 / 출시 기준

## 테스트 계층

1. **Schema/unit**: ID 유일성, 필수 출처, 타입, 좌표 구조, 장 범위 유효성.
2. **Story invariance/property**: 이벤트마다 가능한 모든 choice 경로는 동일 `canonicalOutcomeId`와 `canonicalNextEventIds`로 수렴. 데이터가 비대해지면 property-based testing 도입.
3. **Canonical coverage**: 66권, 1,189장, canonical order, 장별 컨텐츠 상태 누락 0.
4. **Parallel text**: 같은 사건의 다른 본문이 서로를 덮어쓰지 않음.
5. **Historical QA**: UI의 역사 주장과 `historical_claims` 레코드 1:1 대조, 문장별 범위 제한 확인.
6. **Geospatial QA**: 시대 밖 도시/영역 숨김, 좌표 null 처리, 불확실한 경계 점선/미표시.
7. **Licensing QA**: 사용권 없는 번역 텍스트, 박물관 사진, 타일을 번들에 포함하지 않음.
8. **Accessibility/responsiveness**: 화면 회전/키보드/스크린리더/고대 지명 텍스트 목록으로 대체 가능.
9. **Offline & storage**: 느린 네트워크, 새 콘텐츠 버전, 브라우저 정리, 데이터 내보내기/복원.

## P0 자동 실패 조건

- 출처 참조 없는 외부 역사 주장, `factcheckStatus = verified`인데 출처 0건
- 시나리오 선택이 왕국/사건 결과·정경 사건 ID를 수정
- 모든 선택지의 결말이 같지 않음
- 66권/1,189장 색인 누락
- 사용자 화면에 미검증 내용을 확정사실이라고 표기
- 미확인 저작권 자료 번들
- 역사 이벤트가 수록되어 있는데 성경 위치를 참조하지 않은 경우(`externalHistoricalEvent`는 예외)

## 수동 검수 체크리스트 (교사 + 사료 검토자)

- [ ] 역사적 주장의 주어, 행위, 날짜, 장소 각각 출처 확인
- [ ] 성경과 외부 사료의 증언 범위를 혼동하지 않음
- [ ] 논쟁적 연대/지명에서는 견해 및 불확실성 표시
- [ ] 신학 해석이 객관 역사 결과인 양 제시되지 않음
- [ ] 일러스트가 검증된 사실과 자유 재구성을 혼합하여 오해 유발하지 않음
- [ ] 세 모드에서 원문 상충/선택지의 '다른 성경 결과' 없음
- [ ] 지도 범례를 학생이 이해할 수 있음
- [ ] 세로·가로 전환 후 사건/메모/지도 정보 유지
- [ ] 이미지 없이도 성경 위치와 핵심 학습을 이해할 수 있음
- [ ] 허가 상태가 정리된 번역/이미지/지도만 배포

## 학습 정확성 테스트

- 학생이 라기스 전시 자료를 보고 무엇이 독립적으로 확인되는지/안 되는지 구별 가능한지 조사.
- 창조/홍수/출애굽 장면을 본 뒤, 지도 표시가 '확인된 위치'라고 오해하지 않는지 확인.
- 계시록 상징 장면을 현재 지리 지도로 오해하는지 평가.
- '역사 학습'과 '신앙 고백'의 질문이 서로 다른 성격임을 문구로 이해하는지 평가.

## 본 패키지 검사의 한계

`scripts/validate_package.py`는 **메타데이터 무결성**을 검증하며 고고학적 주장 자체, 신학적 해석, 모든 책의 세부 사건 누락 여부를 자동 입증하지 못한다. 최종 정확도에는 검수자의 문헌 대조가 필수이다.
