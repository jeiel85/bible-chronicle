# 16. 게임 방향 — 문명형 흐름의 "게임 같은 교보재"

버전 1.0 / 2026-10-13 / 결정자: 프로젝트 오너

이 문서는 01_PRODUCT의 원칙을 바꾸지 않고, **플레이어가 실제로 무엇을 보고·하고·느끼는지**를 한 곳에 정한다.
결정된 것은 **[결정]**, 제안이며 아직 확정이 아닌 것은 **[제안]**으로 표시한다.

## 1. 한 문장 정의 [결정]

> 문명(Civilization) 시리즈처럼 **시대가 흐르고, 나라가 일어서고 무너지고, 주인공이 바뀌는** 큰 흐름을 따라가며,
> 그 흐름은 **성경의 선형 서사 그대로 고정**되어 있고, 플레이어의 선택은 **보는 방식·배우는 내용·가상 공동체의 삶**만 바꾸는 게임형 교보재.

- 장르 감각: 문명의 "시대 전환·역사적 순간 연출" + 비주얼 노블의 "따라가는 서사" + 가벼운 공동체 경영.
- 문명과 다른 점: 영토 정복·외교·승패로 **역사를 바꾸지 않는다.** 역사는 이미 쓰여 있고, 플레이어는 그 안을 살아 보고 지켜본다.

## 2. 고정 서사 + 수렴형 선택 [결정 — 기존 설계 재확인]

이미 01_PRODUCT §2, 03_TECH §3, `phases/S01A/reference/linear-choice-engine.ts`에 있는 원칙이며 그대로 유지한다.

```text
[에피소드 N] ─┬─ 선택 A (관점/탐색/공동체 결정) ─┐
              ├─ 선택 B ──────────────────────────┼─→ 같은 canonicalOutcomeId ─→ [에피소드 N+1]
              └─ 선택 C ──────────────────────────┘
                 ↳ 달라지는 것: 본 장면, 모은 근거 카드, 메모, 공동체 상태, 연대기 기록
```

- 정경 사건 데이터는 읽기 전용이다. 저장 파일에는 정경 결과가 들어가지 않는다(불러올 때 다시 계산한다).
- 성경에 행동이 기록된 인물의 선택은 분기가 아니라 **"본문은 어떻게 기록하는가"를 확인하는 활동**으로 처리한다.
- 대체 역사(예: "가인이 아벨을 죽이지 않는다", "왕국 분열을 막는다")는 만들지 않는다.

## 3. 시대 흐름: 흥망성쇠와 주인공 교대 [결정]

### 3.1 시대(Era)와 주인공 교대
문명의 "시대"에 해당하는 단위다. 각 시대에는 **시대 주인공**이 있고, 시대가 넘어가면 주인공이 바뀐다.

| 범위 | 시대 주인공 (본문 순서) | 전환 연출 |
|---|---|---|
| 창 1–11 원역사 | 아담 → 노아 | 상징 지도(연도·좌표 없음) |
| 창 12–25 | 아브라함 | 우르/하란 → 가나안 |
| 창 25–36 | 이삭 → 야곱 | 가나안 ↔ 하란 |
| 창 37–50 | 요셉 | 가나안 → 애굽 |
| 이후 캠페인 | 모세 → 여호수아 → 사사들 → 사무엘 → 사울 → 다윗 → 솔로몬 → 분열 왕국 왕들·선지자 | `data/campaign_israel/` 시대 22개 |

- 주인공 교대는 **본문이 이야기의 중심을 옮기는 지점**에서만 일어난다(본문 순서를 따르고, 임의로 고르지 않는다).
- 교대 시점에는 3.3의 "역사적 순간" 화면을 띄운다.

### 3.2 나라의 흥망성쇠
- 세력(애굽, 앗수르, 바벨론, 북이스라엘, 남유다 등)이 시대 지도에 **등장·확장·쇠퇴·퇴장**하는 것을 보여 준다.
- 05_HISTORY_MAP 규약을 그대로 따른다. 근거가 있는 세력 레이어만 그리고, 근거 없는 국경은 그리지 않으며, 두 경계 사이를 보간하는 애니메이션도 금지한다.
- 창세기에는 "나라"보다 도시·민족·가문 단위가 중심이다. 흥망성쇠의 본격적인 연출은 출애굽 이후 캠페인에서 무게가 실린다.

### 3.3 역사적 순간(Historic Moment) 화면 [결정]
문명에서 중요한 사건 때 뜨는 일러스트+텍스트 화면에 해당한다.

| 구성 요소 | 내용 |
|---|---|
| 전면 일러스트 | 16:9(세로 화면은 4:5로 잘라 보여 줌). 항상 "상상 재현 일러스트" 표기 |
| 제목·시대 표기 | 예: "언약의 별 — 족장 시대". 연도는 근거가 있을 때만 |
| 내레이션 2–3줄 | 자체 작성 요약. 창작 문장은 창작 표지 |
| 본문 참조 | `GEN.15.5` 형태의 링크(번역 본문은 사용권 확보 후에 넣음) |
| 버튼 | "연대기에 기록" → 플레이어 연대기에 추가, 다음으로 진행 |

- **트리거**: 시대 전환, 주인공 교대, 언약·약속, 세력의 등장과 멸망, 이주·포로처럼 서사의 큰 분기점.
- **창세기 후보 [제안, 약 18개]**: 창조, 에덴에서 추방, 홍수, 무지개 언약, 바벨, 아브람의 부르심, 별의 언약(15장), 할례 언약(17장), 소돔의 멸망, 이삭의 출생, 모리아(아동 안전 연출), 벧엘의 꿈, 이스라엘이라는 이름, 요셉이 팔림, 요셉이 총리가 됨, 형제의 재회, 애굽 이주, 야곱의 축복과 죽음.
- 일러스트 제작은 **역사적 순간부터** 한다. 에피소드 179개 전부를 원화로 만드는 대신, 순간 약 18장을 먼저 원화로 만들고 나머지 에피소드는 장소 배경과 인물 초상을 조합한다(17_ART_PIPELINE).

## 4. 네 가지 시점 [결정]

01_PRODUCT §3의 세 모드(관찰자 / 성경 인물 / 가상 목격자)에서 **성경 인물을 중심인물과 주변인물로 나눠** 네 가지로 정리한다.

| 시점 | 데이터 값 | 누구인가 | 할 수 있는 것 | 금지 |
|---|---|---|---|---|
| **관찰자** (기본) | `observer` | 과거를 지켜보는 현대의 "나" | 지도·연표·근거 카드를 자유롭게 열람하고, 본문과 사료를 비교 | — |
| **중심인물** | `protagonist` | 시대 주인공(아브라함, 요셉 등) | 그 인물의 자리에서 장면을 보고, 본문이 기록한 행동을 확인 | 기록에 없는 대사·속마음을 사실처럼 쓰는 것, 행동을 바꾸는 것 |
| **주변인물** | `supporting` | 본문에 등장하는 조연(하갈, 롯, 리브가, 유다 등) | 같은 사건을 다른 자리에서 다시 보기("이 장면에서 하갈의 자리는?") | 중심인물과 같은 제약 |
| **제3자** | `witness` | **가상 인물**(이름·사연 모두 창작) | 정경 사건 곁에서 살아가는 가상 공동체를 운영(§5) | 실제 인물처럼 인명록에 넣는 것, 정경 사건의 원인이나 당사자가 되는 것 |

- 중심인물·주변인물 시점에서 본문 밖 내면 묘사가 필요하면 항상 `fictional_reconstruction` 표지를 붙이고, 본문 인용과 다른 스타일로 보여 준다.
- 제3자 시점의 모든 텍스트는 `invented_fiction` 표지를 단다.
- **데이터 이관**: 기존 `phases/S01*` 데이터의 `set_perspective` 값(`observer` 167, 인물 이름 10, `fictional_witness` 2)을 위 네 값과 `characterId`로 옮긴다. 예: `{"perspective":"protagonist","characterId":"noah"}`. 캠페인 계약(11_CAMPAIGN_PRODUCT §5)의 `selectedPerspective`도 같은 네 값으로 맞춘다.

## 5. 가상 공동체 운영 [결정: 도입 / 세부: 제안]

게임다운 "결정과 결과"가 실제로 일어나는 유일한 축이다. 정경을 건드리지 않고도 문명 같은 경영 감각을 준다.

### 5.1 불변 규칙 [결정]
1. 공동체와 그 구성원은 **전부 가상**이며 항상 그렇게 표시한다.
2. 공동체는 정경 사건의 **원인이 되지도, 결과를 바꾸지도 않는다.** 방향은 한쪽뿐이다. 정경 사건이 공동체의 환경을 바꾼다(기근, 전쟁 소식, 이주).
3. 공동체 상태는 정경 데이터와 **다른 저장소**에 둔다. 공동체 상태가 어떻든 다음 정경 에피소드는 똑같이 열린다.
4. 생활사(목축, 우물, 교역, 곡물 저장 등) 묘사는 출처가 있는 일반 배경만 쓴다(05_HISTORY_MAP 분류 `external_secondary`).
5. **게임 오버는 없다.** 공동체가 어려워지면 회복 이벤트로 이어지고, 점수 대신 연대기 기록을 남긴다. 신앙·구원·의로움에는 점수를 매기지 않는다(01_PRODUCT §4).

### 5.2 공동체가 대를 잇는다 [제안 — 추천]
- 플레이어의 가상 가문이 **시대를 건너 대를 이어 가며** 역사를 함께 목격한다(문명의 "문명 하나를 끝까지 키우는" 감각).
- 예: 하란 근처 목축 가문 → 가나안의 이웃 목자 → 요셉 시대 애굽으로 곡물을 사러 내려간 가문 → (캠페인) 광야 진영의 한 가족 …
- 대안: 시대마다 새 공동체로 시작. 매 시대 시작이 깔끔하지만 이어지는 맛은 약하다.

### 5.3 창세기 공동체 결정 예시 [제안]
| 정경 배경 | 공동체 상황 | 플레이어 결정 (정경 영향 없음) | 학습 연결 |
|---|---|---|---|
| 창 12:10 기근 | 목초지가 마름 | 남쪽으로 이동 / 머무르며 우물 파기 / 교역으로 곡물 마련 | 족장 시대 목축과 기근 |
| 창 13 롯과 분리 | 이웃 가문과 목초지 분쟁 | 나누기 / 협상 / 다른 골짜기로 이동 | 본문의 분리 장면과 비교하기 |
| 창 18 마므레 | 낯선 나그네 방문 | 환대 방식 선택 | 고대 근동의 환대 관습 |
| 창 26 우물 분쟁 | 우물을 빼앗김 | 새 우물 / 협상 / 이동 | 이삭의 우물 이야기와 함께 읽기 |
| 창 41–47 7년 풍년·기근 | 곡물 비축 | 저장 비율, 교역, 애굽으로 사러 가기 | 요셉의 정책과 애굽의 곡물 행정(출처 범위 안에서) |

- 자원 후보: 가축, 물, 곡물, 천막·주거, 교역품, 공동체 화목도. 수치는 학습과 몰입을 위한 단순한 수준으로 두고, 전투력·병력 수치는 두지 않는다.

## 6. 한 에피소드의 플레이 흐름 [결정: 골격 / 제안: 세부]

```text
시대 지도(세력·장소, 근거 있는 것만)
  → (해당 시) 역사적 순간 화면
  → 에피소드 장면: 본문 요약 + 시점 렌즈 선택
  → 인터랙션: 근거 카드 탐색 / 지도 관찰 / 인물 관계 / 공동체 결정
  → 정경 결과로 합류(모든 경로가 같은 결과)
  → 복습 질문·연대기 기록 → 다음 에피소드(고정)
```

**게임적 인터랙션 목록**: 근거 카드 수집(도감), 지도 핀 탐색, 시점 전환 다시 보기, 공동체 결정, 인물 계보와 관계도, 복습 퀴즈(해석이 갈리는 문제는 단일 정답 금지), 플레이어 연대기(일지).

## 7. 첫 플레이 가능 구간(버티컬 슬라이스) [제안]
- **추천: 요셉 시대(창 37–50).** 주인공 교대(야곱→요셉), 나라(애굽) 연출, 기근과 곡물 경영이 공동체 시스템과 가장 잘 맞고, 장면 데이터(S01D)도 가장 최근에 만들어졌다.
- 대안: 아브라함 시대(창 12–25). 이야기 시작점이라 자연스럽고, 이주·우물·환대 결정이 어울린다.

## 8. 미결정 사항
1. 공동체: 대를 잇는 방식(§5.2 추천)과 시대마다 새로 시작하는 방식 중 무엇으로 할지.
2. 첫 버티컬 슬라이스 구간(§7).
3. 역사적 순간 목록 확정(§3.3 후보 18개).
4. 클라이언트 기술: 03_TECH는 웹 PWA(React)를 전제로 한다. 게임 연출 비중이 커지면 엔진(Godot 등)을 다시 검토할지.
