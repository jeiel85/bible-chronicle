# 17. 일러스트 제작 파이프라인 — 외부 이미지 에이전트 요청 방식

버전 1.0 / 2026-10-13 / 결정자: 프로젝트 오너 (ripple-garden과 같은 방식)

`genesis_illustration_pack_v1_10/`의 25장은 **참고용 시안**이다. 스토리보드에서 잘라낸 301×111px 조각을 960×540으로 늘린 것이라, 정식 일러스트는 아래 방식으로 새로 만든다.
화풍과 고증 원칙은 07_ART_DIRECTION을 따르고, 이 문서는 **제작 방법과 요청 규칙**을 정한다.

## 1. 도구

```bash
python tools/codex_images.py art/requests/<batch>.json art_out/<batch> [workers] [--backend codex|agy]
```

- 1차로 Codex CLI(`codex exec`의 이미지 생성), 막히면 Antigravity CLI(`agy -p`)로 자동 전환한다.
- 작업 파일은 `[{"id", "kind": "scene"|"sheet", "prompt", "refs": [...]}]` 형식이다. 결과는 `art_out/<batch>/<id>.png`에 저장되고, 이미 있는 id는 건너뛴다.
- `art_out/`은 git에서 제외한다. 검토를 통과한 그림만 `art/`로 옮겨 커밋한다(§4).
- 공통 화풍 문구는 도구 안(`STYLE`)에 한 번만 둔다. 작업 파일의 `prompt`에는 장면 내용만 쓴다.

## 2. 제작 순서 (일관성 우선)

1. **캐릭터 시트**(`kind: sheet`): 시대 주인공과 주요 조연. 얼굴과 복식을 고정한다. 아브라함·사라·이삭·리브가·야곱·라헬·레아·요셉·유다 등, 나이대가 바뀌는 인물은 나이대별로 만든다.
2. **역사적 순간 원화**(`kind: scene`, 약 18장, 16_GAME_DIRECTION §3.3): 해당 인물의 시트를 `refs`로 1장 첨부한다.
3. **장소 배경**: 우르, 하란, 세겜, 벧엘, 마므레, 브엘세바, 애굽 등. 에피소드 179개는 배경과 인물 초상을 조합해 표현한다.
4. **가상 공동체**(제3자 시점) 생활 장면. 이름 없는 주변 사람들이므로 캐릭터 시트를 만들지 않고, 주인공처럼 클로즈업하지 않는다. 성경 인물이나 정경 장면과 한 그림에 넣지 않는다(16 §5.1).

참조 그림은 작업당 1장으로 제한한다(토큰 비용 때문이다. 여러 장이 필요하면 한 장에 나란히 붙인다).

## 3. 요청 공통 규칙 (모든 프롬프트에 해당)

v1.10 시안에서 실제로 나온 문제를 막는 규칙이다.

| 규칙 | 이유(시안의 문제) |
|---|---|
| 글자·라벨·캡션을 넣지 않는다. 지도는 그리게 하지 않는다 | 스토리보드 지도 라벨이 깨짐. 지도는 검증된 데이터로 게임이 그린다 |
| 인물은 고대 근동 사람의 외모로 | 시안 대부분이 서구풍 얼굴 |
| 본문이 "사람"이라고 하는 존재는 사람으로 그린다. 날개·후광은 본문 근거가 있을 때만 | 창 32 씨름을 날개 달린 천사로, 창 18 방문자를 후광 있는 인물로 그림 |
| 아동 안전: 칼을 든 장면, 결박된 아이, 피는 직접 그리지 않고 상징적인 구도로 | 창 22 시안이 결박된 이삭 위로 칼을 든 장면 |
| 창 3 벌거벗음, 창 19·34·38의 성폭력과 착취는 암시하지도 직접 묘사하지도 않는다 | 07_ART_DIRECTION §6, S01C/S01D 안전 문서 |
| 신적 존재를 사람 얼굴로 그리지 않는다(빛·구름·소리 등으로 표현) | 신학적 논쟁 회피 |
| 바벨탑·방주·에덴 같은 원역사 장면은 특정 유적을 그대로 복제하지 않는다 | S01A 원칙(에테멘안키를 실증 자료처럼 쓰지 않음) |
| 시대 혼용 금지: 족장 시대에 철기, 낙타 대군, 로마식 건축 등을 넣지 않는다 | 07 §6 그래픽 검수 |
| 문명 시리즈 등 기존 게임의 UI·화면·트레이드 드레스를 흉내 내지 않는다 | 07 §5 |

## 4. 받은 뒤 처리

1. **검토**: 위 규칙과 07 §6 체크리스트로 본다. 탈락하면 프롬프트를 고쳐 다시 요청한다(같은 id의 파일을 지우고 다시 실행).
2. **채택**: `art/<category>/<id>.png`(category: `moments`, `places`, `characters`, `community`)로 옮기고 매니페스트에 기록한다.
3. **매니페스트 필드**(07 §1과 v1.10 매니페스트 호환): `assetId`, `subjectEventId`, `scriptureRefs`, `kind`, `createdWithAI: true`, `generator: "codex"|"agy"`, `prompt`, `refs`, `fictionalElements`, `historicalAccuracyStatus: "not_verified"`, `rightsStatus: "usage_terms_check_required"`, `reviewer`, `reviewedAt`.
4. **크롭**: 16:9(가로·PC)와 4:5(모바일 세로)는 같은 원본에서 잘라 쓴다. 그래서 프롬프트는 주제를 가운데 1/3 안에 두도록 요구한다.
5. 시안(v1.10)의 `assetId`·`subjectEventId`는 유지하고 `imageFile`만 새 그림으로 바꾼다(ART_ASSET_INTEGRATION).

## 5. 권리와 표기

- AI 생성 이미지의 이용 조건은 생성 서비스(OpenAI/Google) 약관을 배포 전에 확인한다. `rightsStatus`는 확인 전까지 `usage_terms_check_required`로 둔다.
- 게임 안에서는 항상 "상상 재현 일러스트"로 표기하고, 유물·사료 사진과 시각적으로 구분한다(04_UI_UX).
