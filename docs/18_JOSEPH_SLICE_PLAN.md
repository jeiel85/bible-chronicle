# 18. 첫 버티컬 슬라이스 — 요셉 시대(창 37–50) 구현 계획

버전 1.0 / 2026-10-13 / 근거: D-007(공동체 대잇기), D-008(요셉 시대), D-009(웹 PWA)

## 1. 목표

한 시대를 처음부터 끝까지 **실제로 플레이**할 수 있게 만든다. 이를 통해 16_GAME_DIRECTION의 핵심 경험(고정 서사, 역사적 순간, 네 가지 시점, 가상 공동체)이 재미있고 교육적으로 동작하는지 확인한다.

- 범위: `phases/S01D`의 에피소드 64개(`ep-gen-116` ~ `ep-gen-179`), 절 449개.
- 시작: 시대 전환(야곱 → 요셉). 끝: 야곱의 축복과 죽음, 그리고 출애굽으로 넘어가는 잠긴 전환점(`handoff-exo-001`).
- 공개 상태: 개발 미리보기. 콘텐츠 검수와 사용권 확인 전에는 외부 공개 교보재로 부르지 않는다(06_BACKLOG 배포 게이트).

## 3. M1 설계 결정

- **콘텐츠는 원본 JSON을 직접 읽는다.** `phases/S01D/data/*.json`을 빌드 시점에 가져온다. 원본 파일은 고치지 않는다(v1.x 패키지들의 바이트 보존 원칙).
- **에피소드는 "허브" 방식으로 진행한다.** 원본 장면 그래프는 도입 → 갈래 하나 → 확정 결과로 이어진다. 슬라이스에서는 도입 화면을 허브로 삼아 여러 갈래(관점·근거·지도·퀴즈)를 자유롭게 둘러보고 돌아올 수 있게 하고, "이야기 계속"을 누르면 확정 결과로 간다. 갈래는 UI 상태만 바꾸므로 정경 불변 원칙과 충돌하지 않는다.
- **엔진 불변식**: 엔진 상태에는 정경 결과 필드가 없다. 다음 에피소드는 항상 데이터의 `canonicalNextId`에서 나온다. 테스트로 모든 갈래 조합에서 결과와 다음 에피소드가 같은지 확인한다.
- **저장**: IndexedDB에 진행(현재 에피소드·장면, 방문한 갈래, 퀴즈 답, 메모)만 둔다. 정경 결과는 저장하지 않고 불러올 때 데이터에서 다시 계산한다.

## 4. M4 결과와 범위 조정

- **네 가지 시점**: 원본의 옛 시점 값은 `migratePerspective`로 옮긴다(원본은 고치지 않음). 중심인물·주변인물 렌즈는 v1.9 절별 해설에서 그 인물이 언급된 절만 보여 주고, 속마음이나 대사를 만들지 않는다. 창 38장처럼 요셉이 없는 장면에서는 중심인물 렌즈가 다른 사람을 대신 따라가지 않는다. 제3자 렌즈는 가문 소식으로 안내한다.
- **근거 카드 도감**: 에피소드에서 연 근거 카드가 모인다(`collectedCardIds`).
- **v1.9 절별 해설**: 빌드할 때 Vite 플러그인(`virtual:joseph-verse-notes`)이 2MB 원본에서 449절 분량만 뽑는다. 파생 파일은 커밋하지 않는다.
- **지도는 미룸**: S01D 장소 10곳 모두 검토된 좌표가 없어서, 지금 붙이면 점 하나 없는 빈 지도가 된다. 장소 카드(위치 미확정 표시)는 그대로 두고, 좌표 검토 뒤에 붙인다(BACKLOG).
