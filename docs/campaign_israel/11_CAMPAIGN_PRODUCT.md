# Israel: From Promise to Exile — 핵심 캠페인 제품 명세

버전 1.1 / 설계 추가분 / 2026-10-12

## 0. 정의와 완성 범위
- **범위:** 아브라함(창 12장)에서 북이스라엘의 앗수르 멸망(왕하 17장), 남유다의 바벨론 멸망(왕하 25장), 포로기의 목소리까지. 창 1–11장은 신학적 서문, 에스라·느헤미야와 회복 관련 문서는 에필로그.
- **대상:** 초등 고학년~성인, 일반 독자, 주일학교 교사·설교자. 미성년자 보호를 위한 폭력·성폭력·자녀 희생 관련 안전 표현 수준 필요.
- **구성:** `campaign_periods.json` 21개 시대/에필로그 + 시간 미확정 독립 서가 1개, `campaign_events_index.json` 219개 에피소드 **집필용 색인**. 역사 본문 686장에 장 단위 색인 링크, **모든 절과 상세 사건의 검토가 완료되었다는 뜻이 아님**.
- **저술 상태:** 모든 사건 `outline_not_authored`, 모든 역사 검토 `pending_per_event_review`. 책 전체의 원고, 일러스트, 역사 지도 폴리곤이 완료되지 않았음.

## 1. 불변 원칙

1. **성경 속 사건은 변경 불가능**: 왕국 분열·멸망·인물의 죽음·포로 이동을 사용자가 뒤집지 못한다.
2. **비판 없는 승리 놀이 금지**: 정복, 포로 수송, 학살을 점수 획득이나 땅따먹기 쾌감으로 포장하지 않는다. 열왕기·역대기의 서술 의도와 역사적 인간 피해를 함께 보여준다.
3. **시간축과 문학 배열 분리**: 열왕기·역대기는 병행본문으로 연결하되 연대기 중복으로 기록하지 않는다. 예언서 본문의 배열을 사건 발생 날짜로 자동 간주하지 않는다.
4. **외부 사료가 말한 내용만 확인**: 성경 신학의 참/거짓을 도장 찍지 않는다. 비문과 역사 자료가 입증하는 구체 항목만 연결한다.
5. **유저 선택 영향은 학습에만**: 학습 목표·지도 초점·자료 비교 순서·인물 관찰 시점만 바뀐다. 결과 고정 해시/사건 그래프 변경 금지.
6. **종교교육 맥락 투명성**: 기본 모드는 개신교 66권의 정경 흐름을 따르지만 교파별 해석을 '고고학적 확인'으로 오인시켜선 안 된다.

## 3. 캠페인 진입 경로

- **전체 여행(Chronicle):** P00→P20, PXX는 시간축 외 독립 서가. 초심자용 안내.
- **두 왕국 비교(Split View):** 왕상 12장에서부터 북/남 두 레인과 아람·애굽·앗수르·바벨론을 한 화면에 표기. 태블릿/PC 비교 가능, 모바일 세로에서는 레인 전환/비교 오버레이.
- **성경 공부(Classroom):** 교사가 원하는 구간(예 왕하 21장 므낫세, 왕하 23장 요시야, 왕하 25장 멸망)만 선택, 7~10분 카드+학습 질문+종료 복습.
- **지도만 탐험(Atlas):** 모든 레이어에 사료 등급, 시대 범위, 예상 오차와 화면별 레이블 부착.
- **가상 목격자:** 목격자의 이름과 개인 일화는 `invented_fiction` 표시. 성경 실제 인물이 속마음이나 대사를 한 것처럼 서술 금지.

## 4. 화면 구성과 UI 상태

### 모바일 세로 (가로 360–480 CSS px)
- 헤더: 시대/사건, 상단 가느다란 시대 막대.
- 탭 3개: **이야기 / 지도 / 증거**. 지도는 손가락 제스처, 확대 원복.
- 하단: 사건 카드, 다음 사건, 본문, 교사용 질문.
- 분열 이후: 북/남 토글; 국가 간 왕의 동시 재위는 타임라인 미니뷰.

### 모바일 가로·태블릿 (약 600–1199 CSS px)
- 왼쪽 지도 55%, 오른쪽 사건/본문 45% (기기 가로 길이 따라 재배치).
- 사건 선택은 UI 필터일 뿐 저장된 정경 상태를 변경하지 않는다.

### PC (1200 CSS px 이상)
- 왼쪽 가변 정보 트리(20%), 중간 역사 지도·일러스트(55%), 오른쪽 본문/사료(25%).
- 단축키: 좌/우=이전/다음, M=지도, B=본문, E=사료. 화면읽기 도구용 대체 텍스트, 키보드 조작 동등 제공.

### 화면 회전
- CSS 반응형과 orientationchange/ResizeObserver를 독립 처리. 회전해도 현재 이벤트/본문 절/지도 중심/확대 비율/스크롤/음성 위치 유지.
- 모바일 브라우저 강제 방향 잠금에 의존하지 않는다. 사용자가 직접 탭으로 지도를 크게 펼치는 데스크톱/모바일 공용 Focus Mode 제공.

## 5. 서사 진행 계약

```ts
interface CampaignProgress {
  campaignId: 'israel-origins-to-exile';
  activeEventId: string;
  completedEventIds: string[];
  selectedPerspective: 'biblical_view'|'fictional_witness'|'historian';
  selectedLane?: 'north'|'south'|'both';
  inspectedEvidenceIds: string[];
  teacherPresetId?: string;
  // factionOwner, alive/dead king, canonicalOutcomeId, nextCanonicalEvent: 금지
}
```

- 잠금된 결과값은 **저장파일 외부 정경 데이터**에만 존재하며, 선택지는 immutable events payload를 수정할 수 없다.
- 예언서의 선형 이벤트 정렬이 논쟁적이면 예언서는 **사이드카 학습 카드**로 연결, 연표의 숫자 타임스탬프에는 신뢰도 없이는 연결하지 않는다.

## 6. QA · 출판 완료 조건

1. 이벤트마다 핵심 본문(장→절), 병행본문, 화면 요약, 관점 구분, 신학/역사 구별, 역사 논쟁 명시 필요.
2. 686장 단위 캠페인 인덱스 연결은 통과 조건의 1단계. `not_yet_mapped` 0건 + 절/단락별 편집 리뷰가 있어야 콘텐츠 완료로 인정.
3. 3인(본문 교정, 고대사 검토, 교육 품질)의 책임과 리뷰 로그 필요. 한 명이 3영역 모두 검수했다면 이해충돌/검토 한계 표시.
4. 사료에 실리지 않은 고대 국경·정확한 날짜는 연표의 ‘미확정’ 처리, 고정 선/확정 숫자 금지.
5. 미성년자 전용: 신체적 학대와 전쟁 범죄 이미지 직접 노출 기본값 OFF. 설명의 핵심을 누락하지 않으면서 강도 조절.
6. 종이/디지털 교보재용 이미지 라이선스는 이미지별 확인: 외부 박물관 사진은 인용 URL만으로 앱 복제 허가된 것이 아님.
