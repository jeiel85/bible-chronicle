## 배포 가능성 판단

- **데이터 인덱스 개발 착수:** 가능. 219개 스토리 카드의 최소 셸 렌더링과 필터, 왕조 관계, 성경 장 리디렉션을 바로 구현 가능.
- **완성된 역사 게임으로 공개:** 아직 불가. 본문 절별 원고/전 시대 지도/사료/일러스트/라이선스가 비어 있음.
- **추천 첫 실제 교육용 Vertical Slice:** P16 므낫세→P17 요시야→P18 바벨론 멸망. 왕하 21~25 및 대하 33~36, 렘 일부를 수작업 검증 후 콘텐츠로 우선 공개.
- **그 다음:** P09~P10 분열, P14 북왕국 멸망, P08 다윗 왕조, P01~P06 초기 역사 순으로 확대.
