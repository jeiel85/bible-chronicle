# 클로드 코드 / Codex 구현 인수인계

## 입력과 권한
- 이 ZIP 하나를 프로젝트 루트에 배치한다. 기존 1.7 원본 217개 파일은 새 1.8 파일과 충돌 없이 유지한다.
- `python bible_chronicle_design/genesis_completion_v1_8/scripts/validate_v18.py` 실행.
- 이어서 기존 마스터·S01A~D·이스라엘 캠페인 검증기를 실행한다.
- `demo/Genesis_Content_Viewer.html`은 파일 더블클릭으로 동작하며 원격 접속, 광고, 분석 SDK가 없다.

## 화면 연결
- `verse_study_cards_1533.json`: 장·절 색인과 학습 초점. 단순 학습 카드와 실제 독립 주석 초안 구별.
- `episode_release_profiles_179.json`: 본문 시나리오·고정 결말·민감도 표시.
- `chapter_teaching_guides_50.json`: 장별 설명과 주의사항.
- `teacher_units_12.json`: 연령 수준에 따른 12차시 구간.
- 별도 라이선스 확정 전 개역개정 본문/박물관 이미지 표시 금지.

## 성경 세계 지도
- Genesis 1~11은 상징적 배치 또는 불확실성 카드로 보여주며 역사적 좌표를 만들지 않는다.
- Genesis 12~50은 검증된 고대 지명 수준으로만 안내하고, 길·경계·연대에는 `unresolved` 상태를 유지한다.
- 창 46~50은 가나안→애굽의 **이야기 속 이동**을 보여주되 실제 출발 지점 및 경로 세부를 GPS로 단정하지 않는다.

## 사용자 행동 제한
- 결과 고정: `ep-gen-001` ... `ep-gen-179` → 출애굽 연결 고정. 왕국 역사 ID와 충돌하지 않는다.
- 사용자 선택이 바꿀 수 있는 것: 자료열람 순서, 관찰자/문헌/문맥 보기, 퀴즈 표시, 일러스트 상세 보기.
- 바꿀 수 없는 것: 인물의 죽음·언약·심판·역사적 결과·성경 본문.
- 교실 어린이 모드: 창 4, 6~9, 19, 22, 34, 38~39 등은 보호된 연출과 교사용 대화 문항을 사용한다.

## 실제 배포 전 남은 차단 조건
1. 1,459절 독립 주석 초안 작성·대조.
2. 신학·역사·교육 전문가 인간 검토 및 증빙.
3. 한국어 성경 본문과 삽화별 라이선스 허가.
4. 외부 공개 매체에 배포할 게임 코드 및 접근성 테스트.
