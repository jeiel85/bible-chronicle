## 중요 해석 정책

1. 창 1–11은 원역사 서술로서 본문의 의미와 고대근동 비교를 분리. 신앙적 수용과 실증 과학의 차이를 설명.
2. 족장·요셉 개인의 활동 연대·실존·파라오 신원을 외부 고고학이 확정했다는 주장 금지.
3. 옥스퍼드 자료 중 다수는 **초록만 열람**. 책 전체를 읽고 논문 심사를 마쳤다고 주장하지 않음.
4. 창 38장, 34장, 19장, 39장 등의 성적 폭력·착취·보복에 대한 연령별 안전성 검토 필요.
