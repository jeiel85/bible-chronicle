# 검토 및 승인 프로토콜 (GENESIS EDITORIAL REVIEW)

## 역할별 독립 검토

1. **본문·원어 담당:** 한국어 본문 사용권 확인, 절 번호·누락·히브리어 변이·시적 언어·장르 검토. `reviewerId`, `sourceEdition`, `date`, `accept/reject`, `issues` 기록.
2. **신학 담당:** 본문 관찰과 신학적 적용/후대 기독교 독해를 구별, 교단별 이견 표기. 설교용 예화와 실제 본문을 혼합하지 않음.
3. **역사·고고학 담당:** 유적·비문·원문헌·2차 문헌의 입증 가능 범위 확인. 학술서의 초록만 읽었다면 `abstract_only` 유지.
4. **교육·보호 담당:** 성폭력(19·34·38·39장), 인신매매(37장), 인신희생 위험(22장), 종족 편견(9장) 등 연령별 접근성 검토.
5. **법무·라이선스 담당:** 성경 번역권·유물사진·배경음악·생성 이미지의 배포 조건 개별 확인.

## 사건별 검토 완료 조건

- 편집 초안과 외부 학술 근거를 분리하여 설명하고, 모든 중요한 주장에 직접 관련된 자료 URL·페이지(확인한 경우만)를 붙인다.
- 실증 불가능한 사건은 `biblical_account_not_independently_established` 상태로 남긴다. 그것이 무조건 거짓임을 뜻하지 않는다.
- 정확한 지리·연대·고유명사를 모르면 `unknown`을 유지한다.
- 두 개 이상 독립된 자료로 평가 가능한 역사 주장은 상호 검토하고, 직접 사료/현대 연구를 구별한다.
- 모든 절에 **직접 집필한 개별 주석**이 있어야 한다. 장 주석의 자동 복제를 개별 해설로 계산하면 안 된다.
- 검토자 승인 기록이 포함되기 전에는 `publicationReady=false`.

## 서명 가능한 감사 기록 예시

```json
{
  "ref": "GEN.41.1",
  "reviewArea": "history",
  "reviewer": null,
  "credentials": null,
  "reviewDate": null,
  "sourceIds": ["OUP-HOFF"],
  "decision": "pending",
  "notes": "요셉의 파라오 신원은 확정 불가",
  "publicationReady": false
}
```

**외부 전문가의 동의 없이 reviewer 필드를 채우거나 완료로 선언하지 않는다.**
