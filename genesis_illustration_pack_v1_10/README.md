# Genesis Image Starter Pack v1.10

**실제 생성 이미지가 포함된 창세기 콘셉트 아트 패키지**입니다.

- 생성된 원본 스토리보드: **3장** (각 1536×1024 PNG)
- 장면별 분리 시안: **25장** (각 960×540 프리뷰 PNG + 실제 자르기 원본 25장)
- 기존 179개 에피소드에서 **25개**에 장면별 시안을 연결했으며, 나머지 **154개**에는 아직 개별 이미지가 없습니다.
- 장면별 시안은 스토리보드에서 자른 것으로, **개별 생성한 고해상도 원화 25장이 아닙니다.**
- 일부 그림에는 시대·건축·인물·상징 묘사의 오류가 있을 수 있으므로 정식 배포 전 수정해야 합니다.
- 이 문서는 역사적 사실이나 성경 구절의 사진 증거를 제공하지 않습니다.

## 열어보기

1. `demo/Genesis_Art_Gallery.html`을 로컬 브라우저로 엽니다.
2. `scenes/` 아래의 PNG는 게임 MVP에서 교체 가능한 임시 시안입니다.
3. `original_storyboards/`의 3개 PNG는 전체 기획 무드보드입니다.
4. `data/genesis_art_manifest.json`은 에셋 메타데이터와 장절/에피소드 매핑입니다.
5. `data/episode_asset_lookup_179.json`은 179개 에피소드 기준 자산 매핑입니다.

## 주의사항

- 창조·에덴·홍수 등은 역사적 발굴 자료로 확인된 풍경을 그린 것이 아닙니다.
- 바벨탑의 외형, 아브라함/족장의 얼굴, 요셉 시대의 이집트 왕조는 미확정입니다.
- 원본 일부의 신적 존재/천사 묘사와 지리 표기는 신학·역사적 오류를 포함할 수 있어 프로토타입 전용입니다.
- 지도는 별도로 검증된 지리 데이터로 구현해야 하며, 스토리보드에 생성된 지도는 지리 근거로 사용하지 않습니다.
- 새 이미지들의 AI 관련 이용조건은 배포 플랫폼 정책에 맞추어 확인하세요. 제3자 박물관 사진이나 특정 상용 게임 원본은 사용하지 않았습니다.
