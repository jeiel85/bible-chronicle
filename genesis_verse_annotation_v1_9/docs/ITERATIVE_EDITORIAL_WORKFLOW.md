# 지속 교정·검증 운영 정책

## 전문가 감수 필수 요구 제거

외부 감수의 최종 서명은 필수 진행 조건이 아닙니다. 진행 중 발견되는 오류를 기록, 수정, 재배포합니다. 하지만 잘못된 내용을 임의로 사실이라고 확정해서는 안 됩니다.

## 개별 절 리뷰 계약

각 항목은 `ref`, `explanationKo`, `episodeId`, `chapterGuideId`, `editorialStage`, `riskFlag`, `scriptureSource`를 반드시 가집니다.

1. **본문 일치 확인:** 특정 절의 누가/무엇을/어떻게 표현했는지 원문 영어와 사용하려는 한국어 본문을 대조합니다.
2. **성경 내부 해석:** 본문 직접 관찰과 교육용 해석은 구별합니다. 소유권·권력·폭력·피해자의 관점은 특별히 주의합니다.
3. **역사 검증:** 배경 추정·지리 경로·시대연대를 쓸 때는 성경 외 독립 자료와 그 한계를 기록합니다.
4. **수정 기록:** `data/correction_log.json`에 절 번호/구 버전/변경 이유/출처 URL/수정자/수정 날짜를 남깁니다.
5. **구현 테스트:** 화면에서 출처와 불확실성 표시 확인 후 에피소드 연결성을 검사합니다.

## 배포 상태

- `draft_for_internal_iteration`: 목업·내부 교사 테스트 가능, 피드백 수집
- `reviewed_for_classroom`: 내부 교사에 의한 본문 대조·교육 표현 검토 완료(외부 전문가 자격 필요 없음)
- `published`: 실제 배포 용도별 한국어 본문/이미지 라이선스 검토와 개인정보·콘텐츠 표시 완료 이후

미상 날짜·지도 위치, 계보의 계수 차이 등은 추정임을 명시하고 확인 불가능하면 숨기거나 미확정으로 표시합니다.

## 주의 사항

- 창 16장의 하갈, 창 34장의 디나, 창 38장의 다말 등 권력 불균형·폭력 사건의 교육 문구는 원치 않는 경험을 정당화하지 않도록 합니다.
- 창 47장 식량 정책의 결과에 대해서도 권력 집중과 백성의 종속을 함께 설명합니다.
- 창 50장의 선한 결과는 이전 가해행위를 정당화하지 않습니다.
