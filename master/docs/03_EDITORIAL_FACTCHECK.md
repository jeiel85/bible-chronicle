# 03. 편집/역사/성경 해석 검증 규약

## 1. 출처 우선순위와 라벨

**A 성경 본문에 기재:** 구절 범위를 정확히 적고 해석과 직인용을 구별한다. 본문에 직접 나타나지 않는 대사/심리 묘사를 사실로 쓰지 않는다.

**B 외부 사료 확인:** 박물관 소장품, 비문, 동시대 문서, 1차 사료 판본, 고고학 보고서 등으로 검증한 *좁은 범위*만 `external_support`로 승인한다.

**C 학계에서 논의 중:** 주요 견해와 그 근거/대립 견해/연대 및 좌표 범위를 제시한다. 학문적 합의가 확인되지 않았다면 '합의'라 적지 않는다.

**D 신학 해석:** 교파별 해석과 저자의 논증을 표기한다. 특정 교회의 기본 해설 관점과 역사적 증명의 언어를 혼합하지 않는다.

**E 교육 연출:** 실제 존재하지 않는 목격자·시각·대사·단역·대화 창작 등은 시각적으로 `교육적 재구성` 표지.

## 2. 주장별 검수 필드

`claimId, preciseStatementKo, scriptureRefs, evidenceSources, authorName, evidenceScope, contraryViews, datingConfidence, geographyConfidence, representationClass, reviewedAt, reviewer, rightsStatus`.

`sourceId`만 하나 등록해도 자동으로 '역사 사실 확정'이 되지 않도록 검사한다. 역사/신학 감수를 모두 완료한 구체적 문장만 `approved`가 될 수 있다.

## 3. 고고학 카드 편집 예시

- **예후/검은 오벨리스크** — 영국박물관 소장품 118885 설명에는 예후가 낸 조공을 다루는 자료로 기술되어 있다. 이 유물은 예후와 앗수르 간 관계에 관련된 외부 자료이지 열왕기하 9~10장 전체를 입증하지 않는다.
- **라기스 부조** — 영국박물관 소장품 124911에는 산헤립이 라기스 함락 장면을 관찰하는 부조가 있다. 라기스의 공격과 유다 전쟁의 맥락을 연결하되 예루살렘에 대한 결과와 혼합하지 않는다.
- **바벨론 연대기** — 영국박물관 소장품 21946은 기원전 597년 예루살렘 원정을 기술한다. 기원전 587/586년 최종 함락에 대한 다른 근거는 별도로 확보해야 한다.

## 4. 저작권 게이트

1. 개역개정 등 대한성서공회 한글 번역본은 별도 재배포/앱 사용 허가 확인 전 원문 텍스트 파일을 포함하지 않음.
2. 대체 텍스트는 공개 라이선스 확인/출처·변형 표기 후만 사용하며, 영어/그리스어 자유 이용이 한국어 번역 허락을 의미하지 않음.
3. 박물관의 유물 **정보** 링크와 사진 **복제 권한**을 구분. BM 이미지 예시가 CC BY-NC-SA일 경우 상업 배포에는 별도 허가 필요할 수 있음.
4. Natural Earth는 지형 베이스 레이어 용도로만 사용. OSM을 쓰면 ODbL과 attribution, 별도 타일 운영 정책 확인.
5. 제작한 일러스트도 유물 이미지 복제 기반 여부와 모델/작가 사용 계약 기록.

## 5. 승인 게이트

`draft` → `passage_verified` → `claim_reviewed` → `theology_reviewed` → `map_reviewed_or_not_applicable` → `rights_cleared` → `education_reviewed` → `publishable`.

모든 주요 카드에는 `책:장:절`, 출처 URL, 검수자/검수일, 의견 차이 시 `학술적 이견`을 표시한다. 입력된 출처와 실제 진술 사이의 대응이 증명되어야 통과.

## 검수자 권장

성경 본문/문학 감수 1인, 역사·고고학 검수 1인, 교회 교육 감수 1인, 저작권 확인 담당 1인. 동일인이 복수 역할 수행하더라도 서로 다른 검수 체크를 요구.
