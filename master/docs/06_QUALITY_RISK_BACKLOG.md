# 06. 전권 품질검증 체크리스트·우선 작업순서

## 모든 단계 공통 인수 테스트 (Gate)

- C-01 정경 범위: 책·장 정확성, 장 누락 없음, 장별 최소 1개 단락 연결.
- C-02 본문: 인용/서술/후대 해석 분리, 필요시 다중 본문 병행.
- C-03 장르: 시와 법과 묵시는 사건 시뮬레이션으로 재작성하지 않음.
- C-04 선택: 어떤 사용자의 선택도 정경적 사건의 고정 결과를 바꾸지 않음.
- C-05 역사: 연대/지리의 정확도 필드, 미확정·비문·외부 자료 연결 단위 확인.
- C-06 지도: 좌표 없는 사건 핀 표시 금지; 정치 지도에 근거/시간 범위 필수.
- C-07 복음서: 병행 서술, 수난/부활 기록, 주요 본문비평 이슈에 유의.
- C-08 교회 교육: 연령별 민감한 폭력·성폭력·멸망·종교적 갈등 표현 가이드.
- C-09 저작권: 번역 본문·유물 사진·지도 데이터·폰트·삽화·음악 별도 허가.
- C-10 UX: 360x800, 800x360, 1366x768, 1920x1080 기준 레이아웃과 확대 200%.
- C-11 개인정보: 로그인/추적/광고/불필요한 네트워크 호출 없음.
- C-12 안정성: 손상된 저장 데이터 복구, 오프라인/업데이트 버전 호환.

## 우선 순서

**S00(이번 패키지 완료 범위)**: 전체 66권·1,189장 문학 단락 초안, ID 및 테스트, v1.1 보존.

**S01(다음)**: 창세기 50장. 실제 단락별 본문/지도/삽화/선택 시나리오/학습지 초안 + 검수 카드.

**S04 고가치 시연**: 이미 기초가 있는 이스라엘 왕국 캠페인에서 므낫세~요시야~멸망의 핵심 사건을 실제 플레이어블 교보재로 구현. S01과 병렬 수행 가능하되 ID/계약 동일.

**S14 출판 전 단계**: 정확한 판본의 성경 본문 사용권, 모든 화면 표시와 증빙, 전문 검수 결과를 확인할 때만 실제 공개 승인.

## 미결정 사항 기록

- 한국어 성경 판본별 배포 권한/원문 제공 방식
- 역사·신학 감수자를 누구로 둘지
- 앱의 주요 대상 연령(주일학교/청소년/성인)과 민감한 본문 표현 가이드
- 언어 및 교단별 해석 안내 수준
- 지도 제작자/자료 출처/고대 경계 추정 사용 범위
- 추후 네이티브 앱이 필요한지; v1은 PWA

이 항목들을 해결하지 않고 공개 단계 통과 처리하지 않는다.
