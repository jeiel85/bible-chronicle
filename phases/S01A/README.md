# Bible Chronicle — S01-A 창세기 1~11장 상세 설계

**통합 패키지 v1.3.0** · 2026-10-12 · 66권 마스터·이스라엘 캠페인 v1.2 보존 / S01-A 확장

## 무엇을 완성했는가
- 창세기 1~11장 구간을 **22개 에피소드 설계**로 구분하고, 3개의 주요 비트/에피소드, 5개 장면 노드/에피소드, 회귀하지 않는 선택지 5개/에피소드, 삽화 22개 제작 명세, 22개 학습 차시 초안.
- 장절 범위는 창세기 1~11장의 모든 절을 정확히 하나의 에피소드에 연결한다. **성경 번역 본문 텍스트는 포함하지 않는다.**
- 역사/신학/지도 각 검증 상태는 미승인 상태로 보존. 실존 유물의 존재와 성경 사건의 고고학적 입증을 구분한다.
- **전체 66권/1,189장**, 기존 이스라엘 **219개 에피소드 ID**, 마스터 v1.2 자료 보존.

## 여전히 하지 않은 것
- 본문 상세 주석이나 최종 번역·신학·역사 감수, 이미지 파일 제작, 앱 구현, 이미지 사용권 확보.
- 창세기 1~11장의 절별 **에피소드 연결은 구조적으로 완결**, 다만 절별 해석과 교육적 정확성에 대한 사람의 교차 검증은 미완료.
- 지도의 연대·경계·좌표가 미확정이어서 게임 지도가 아닌 도식 렌더링 계약만 정의.

## 파일 읽기 순서
1. `docs/01_CREATIVE_PILLARS.md`: 설계 원칙, 왜 원역사는 정복 지도와 다른가
2. `docs/02_EPISODE_BIBLE.md`: 에피소드별 사건/지도/선택/아트 제약
3. `docs/03_GEOGRAPHY_CHRONOLOGY.md`: 지도와 불확정 위치 방어
4. `docs/04_FACTCHECK_AND_SAFETY.md`: 검증 사례, 민감 장면, 저작권
5. `docs/05_RESPONSIVE_UI.md`: 모바일/데스크톱 설계
6. `docs/06_IMPLEMENTATION_TICKETS.md`: 실제 개발 작업 순서
7. `docs/08_FULL_PLAYTHROUGH_SAMPLES.md`: 가인·홍수·바벨 시나리오의 화면 내 실제 진행 예시
8. `data/*`: 바로 소비할 수 있는 JSON, v1.2 호환 릴리스 슬라이스
9. `scripts/validate_s01a.py`: JSON Schema/정경 결과 불변성/장절 커버리지 자동 검증

## 실행
`python phases/S01A/scripts/validate_s01a.py` (통합 패키지 루트에서 실행)
`python master/scripts/validate_master.py` 및 기존 v1.2 테스트도 동일하게 실행.

검증 통과는 **기계적 무결성**을 뜻하며, 학문적 역사 검증 완료가 아니다.
