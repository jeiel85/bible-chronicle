# 콘텐츠·게임 설계 핵심 원칙

## 서사 방식

창 1~11장은 고대 이스라엘의 왕국 지도처럼 국가 경계·왕조 연대표를 드러내는 서술이 아니다. **원역사(Primeval History)**의 신학적·문학적 구조를 보존한다. 창 1:1~2:3 / 창 2:4~25를 강제로 합성해 정밀 실시간 다큐멘터리처럼 만들지 않는다. 고대 근동의 문학 간 유사성은 사건 입증이 아닌 텍스트 비교 카드로 쓴다.

## 게임 루프

1. 시대의 문학적 좌표 표시(창조/에덴/인류 확산 등; 연도 숫자 없음)
2. 대형 사건 삽화 → 음성 없는 텍스트 요약 → 직접 참조 `GEN.1.1` 형태
3. 선택: `관점 보기` / `본문·고고학 확인` / `개념 지도` 중 하나 또는 반복 방문
4. 본문 요약 재결합(`canonicalOutcomeId` 불변)
5. 지식 카드·퀴즈·교사용 질문 → 다음 에피소드 고정 이동

## 3관점

- 관찰자: 기본, 객관적 탐색 UI로 본문과 근거를 읽는다.
- 인물 관점: 아담/하와/가인/노아의 **서사 관찰창**. 텍스트에 없는 1인칭 주장·대사·심리를 사실로 생성하지 않는다. 플레이어는 살해/불순종/생존 여부를 바꾸지 않는다.
- 가상 목격자: 고대 서사와 관점 교육의 편의적 장치. 실제 등장 인물처럼 인명록에 넣지 않고 **‘교육적 허구’** 레이블 항상 표시.

## 학습 강화

- 원전 결말을 바꾸는 퍼즐/전투/제국 점령 버튼 없음. 건축·전투·정치 수치는 성경 기록과 모순되거나 임의로 조작되기 쉬워 금지.
- 희생·폭력은 12세 미만/어린이 모드에서 상징적 표현과 교사 설명으로 완화. 사용자 설정으로 민감한 장면을 전환 가능.
- 본문 인용은 라이선스 취득까지 책·장·절 링크로 대체.

## 명시적 이슈

- 창 6:1~4의 존재들과 ‘네피림’ 해석 확정 금지.
- 노아의 포도원과 함/가나안의 구절로 현대 인종이나 노예제를 정당화하는 UI/퀴즈 생성 금지.
- 바벨탑·에테멘안키·우르 지구라트를 동일 사건의 실증자료로 표현 금지.
- 사건 내 선택은 관점·정보 표시 수준이며 구약 창조/홍수의 물리적 연대나 장소를 시스템에서 추측하지 않는다.
