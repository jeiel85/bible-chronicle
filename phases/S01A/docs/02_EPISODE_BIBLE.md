# 에피소드 설계서 — GEN 1~11 / 22개

본 문서는 **한국어 원문 저작권 회피를 위해 서사 요약문을 독자적으로 작성**하였고, 원문 구절 인용은 포함하지 않는다. 각 에피소드의 모든 서사 전환은 결과 고정이다.


## ep-gen-001 · 빛과 질서의 시작

**본문:** `GEN.1.1-GEN.1.13` · **서술 증거:** `biblical_literary` · **지도:** `symbolic` · **관점:** 독자·역사 관찰자

**필수 서사 비트**: 태초와 빛의 구분 / 궁창과 물의 구분 / 땅·바다·식물의 등장.

**학습 목표:** 창조 서술의 반복 구조와 질서화

**선택지:** 관점 모드 전환 → 본문·근거를 관찰 → 개념 지도 열기. 어느 선택에도 `canonicalOutcomeId`를 쓰는 권한이 없다.

**지리/역사 주의:** 실제 위치나 경로를 확정할 수 없는 장면입니다. 지도는 학습용 도식입니다.

**삽화:** 빛이 어둠을 가르는 추상적 창조 파노라마

**검증 포인터:** C01; 민감도: 일반.
