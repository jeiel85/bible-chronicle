## 기술 스택

React + TypeScript + Vite PWA + IndexedDB, MapLibre는 연대/위치가 실제 확인되는 구간에서만 도입. 창세기 1~11장은 React SVG 관계도/개념 지도를 먼저 구축하며 정적 호스팅·오프라인 실행을 유지한다. 이미지 로딩은 로컬 자산 우선, 실제 데이터 bundle 버전 도입.

## 수용 테스트

- `release_slice_v1_2.json`는 기존 `master/schemas/release_slice.schema.json`과 호환.
- 전환 선택 후 결과 ID, 다음 ID는 변경 없음.
- 가상의 사용자 관점 선택이 성경 인물의 행동을 수정할 수 없음.
- 지도 좌표가 모두 null이어도 예외 발생 없음.
- 한국어 원문 번역문 내장 0건, 이미지 파일 0개로 시작한다.
- 모든 데이터와 원고 `not reviewed/not publishable`가 자동 검증된다.
