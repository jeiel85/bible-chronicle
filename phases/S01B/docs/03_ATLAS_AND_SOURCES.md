# 창 12–25 지도·사료·연대 실무 규칙

## 지도 레이어 4종
- `modern_geography`: 현대 지명(배경, 참조용). 고대 사건의 증거로 오인되지 않도록 라벨.
- `historic_site_context`: 실제 유적·역사 도시(예: 우르) 관련 **독립 확인** 전용 레이어. 해당 성경 인물의 체류를 입증한다고 쓰지 않는다.
- `biblical_narrative_route`: 창세기의 '하란 → 가나안 → 애굽 → 네겝'을 순서도식 점선으로만 표시. 경로·거리·이동 일수는 생성하지 않음.
- `unlocated_event_zone`: 싯딤·소돔·그랄·모리아 등은 불확정 영역/질문 표시; 점 좌표·정밀 군사 지도·BCE 연대 잠금.

## 사건별 지도 인터랙션
1. 창 12: 세겜, 벧엘, 남방, 애굽의 진행 방향을 텍스트 순서에 따라 공개.
2. 창 13: 롯이 요단 들을 선택하는 비선형 시뮬레이션 **금지**. 두 방향을 클릭해 지형을 비교하되 실제 선택은 고정.
3. 창 14: 네 왕/다섯 왕의 관계 도표와 이동 회상을 제공. 역사적 제국 경계·전쟁 날짜·병력 수는 입력하지 않음.
4. 창 16, 21: 하갈과 이스마엘의 위기/물 찾기는 논픽션 장소 확정으로 해석하지 않게 광야 개념도.
5. 창 19: 도시 유적 좌표가 발견되었다는 연출 금지. 피해 묘사는 비노골적으로.
6. 창 22: `Moriah?`로 표시하며 열왕기/역대기의 예루살렘 성전산과 동일하다고 단정하지 않음.
7. 창 23: 막벨라 굴 성지 전통과 당대 거래 서사를 분리해 두 겹의 설명카드에 표시.
8. 창 24: 하란 지역과 '나홀의 성'을 엄밀하게 같은 좌표로 지정하지 않음. 물 주는 장면은 원경.

## 출처와 도달 한계
`data/source_register.json`은 접근한 URL과 사용 목적을 보관한다. USCCB 성경 본문은 참조·장절 대조 목적으로만 사용하며 본문 텍스트를 재배포하지 않음. UNESCO 자료는 우르가 실제 도시였음을 뒷받침하지만 개인 아브라함의 존재·이동은 입증하지 않는다. 학술 논문 초록은 논쟁 존재의 근거이지 그 논쟁의 최종 답이 아님.

**원문이 확인되지 않은 항목**은 `data/research_register.json`에 검토 대기; 본 설계는 전체 역사 사실 검증이 완료됐다고 주장하지 않는다.
