# 화면 및 반응형 동작 계약

## 6개 고정 장면 노드/에피소드
- `opening`: 성경 서사 세 비트(짧은 내레이션), 사건 카드. 버튼 4개: 인물 관점, 근거, 지도, 질문.
- `lens`: 성경 텍스트를 복사하지 않는 인물/관찰/가상 목격자 세 개 렌즈의 차이 안내.
- `evidence`: 출처 ID, 성경 기록과 외부 입증 여부 분리, '확인할 수 없음' 표시.
- `atlas`: 기호 지도 + 시간축; 미확정 장소 핀 비활성; 14장의 경우 왕국 관계 도표.
- `reflection`: 객관식 이해도와 본문 읽기 권유, 오답 정정. 점수는 학습 진행도만 변경.
- `locked-outcome`: 다른 패널 선택에 상관없이 본문상 사건의 고정 결말을 보여주고 다음으로 진행.

## 3개 반응형 레이아웃
- 휴대폰 세로 `width<600`: 그림 상단 40% 높이, 본문 카드 아래 60%, 지도/근거는 바텀시트, 사건 선택지는 한 열.
- 휴대폰 가로/태블릿 `600<=width<1100`: 아트 좌측 55%, 지도·본문 우측 45%, 정보 탭 상단.
- PC/대형 화면 `width>=1100`: 타임라인 18% / 아트+본문 52% / 지도·검증 30%; 최소 글씨 크기 16px.
- 방향 전환 전후 `episodeId`, `sceneId`, `visitedPanels`, `lessonAnswer`, `accessibilityFlags`가 유지되어야 하며 선택지 흐름 자체는 불변.
- 확대·고대비·키보드·스크린리더·자막/정적인 장면 대체·Reduced Motion 필수.
- 밝기·음성·진동은 선택형; 본문 내용/역사 주장과 점수, 미니게임 결과를 직접 결합 금지.

## 상태 전이
`openEpisode(id) -> opening -> (lens|evidence|atlas|reflection) -> locked-outcome -> nextEpisode`.
서브패널 열람은 순서에 영향을 주지 않는다. 기록되지 않은 fictional choice는 허용하지 않으며 기독교 핵심 인물의 비본질적 결정을 재현하더라도 사실 단정 금지.
