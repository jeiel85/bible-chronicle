# S01C — 창세기 26–36장 상세 설계 (초안 v1.5)

이 폴더는 66권 통합 패키지의 **새 증분 모듈**입니다. 기존 S01A/S01B 및 이스라엘 219개 사건 색인은 수정하지 않았습니다.

- **목적:** 고정된 성경 서사 + 관찰자·성경 인물 렌즈·창작 표시된 목격자 시점 + 지도/일러스트/학습.
- **검증 범위:** 창세기 26–36장 11장, 391절, 52개 에피소드(ep-gen-064 … ep-gen-115).
- **주의:** 사실 검증이 완료된 학술판이 아닌 개발용 설계 초안입니다. 게임과 일러스트 실제 구현 없음.
- **배포 조건:** 성경 원문/교사용 해설/고고학 표기/민감한 사건/사용권은 승인 전 비공개.
- **본문 참조:** NABRE(USCCB) 주해 + KJV(BibleGateway) 절 범위 대조. 한국어 구절 본문은 번역 라이선스 확인 후 별도 확보. NABRE/KJV/국문판 사이의 장절 번호 차이는 수작업 교차 검토.

## 장별 구성

| 성경 | 에피소드 수 | 대표 내용 |
|---|---:|---|
| 26장 | 7 | 이삭에게 이어진 약속 → 에서의 혼인 |
| 27장 | 5 | 맏아들을 부른 이삭 → 형제 사이의 위기 |
| 28장 | 3 | 고향을 떠나는 야곱 → 벧엘의 기둥과 서원 |
| 29장 | 4 | 우물가의 라헬 → 레아의 네 아들 |
| 30장 | 6 | 라헬과 빌하 → 가축 번식 이야기 |
| 31장 | 5 | 떠날 결심 → 언약의 돌무더기 |
| 32장 | 4 | 마하나임과 형 에서의 소식 → 얍복강의 밤과 이스라엘 |
| 33장 | 3 | 형제의 재회 → 세겜에 자리 잡다 |
| 34장 | 4 | 디나에게 일어난 폭력 → 시므온과 레위의 보복 |
| 35장 | 5 | 벧엘로 돌아가다 → 이삭의 죽음 |
| 36장 | 6 | 에서의 가정과 세일 이주 → 에돔의 거주지와 족장 |

## 구현에 필요한 진입점

1. `data/episode_index.json`: 범위·순서·인물·장소·고정 사건 결과 (52).
2. `data/scenes.json`: 인물·지도·근거·복습으로 분기하여 같은 결과에 재합류하는 312개 장면.
3. `data/verse_coverage.json`: 장/절별로 에피소드 ID 하나씩 매핑 (391).
4. `data/lessons.json`: 장면별 본문 확인 문제 초안 52개. **문항 감수 후 공개**.
5. `data/geography.json` + `place_catalog.json`: 좌표 미확정 상태 유지, 현대 지리 지도에 확정 핀 표기 금지.
6. `data/assets_manifest.json`: 52개 일러스트 제작 지시, 실제 이미지 없음.
7. `data/claims.json` + `source_register.json`: 실제로 확인된 웹 출처와 *미승인* 요약 주장.
8. `data/handoffs.json`: S01B `handoff-gen-026` → S01C `ep-gen-064` (기존 에피소드 불변).
9. `data/release_slice_v1_2.json`: 기존 마스터 JSON Schema 1.2.0 준수.
10. `scripts/validate_s01c.py`: 전체 필수 검증. `validate_release_gate.py`는 **배포 전에는 반드시 실패**해야 정상입니다.

## 해석·연대 정책

창세기 26–36장의 인물·사건을 특정 기원전 연대에 고정하지 않습니다. 벧엘·브니엘·숙곳의 특정 지점은 검증된 사실로 선언하지 않습니다. 에돔 계보에 등장하는 ‘이스라엘 왕정 이전’이라는 **본문 내부의 상대적 진술**을 고고학적 절대 연대표로 대체하지 않습니다.
