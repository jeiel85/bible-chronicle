# 역사 지도와 연대 정책

## 세 가지 지도 레이어

- **성경 기록상의 지명**: 성경의 지명과 상대적 이동 순서만 나타냅니다.
- **현대 위치 후보**: 고대의 특정 지명이 연구되는 경우에만 연구처·일자·이견을 표시하는 별도 토글입니다. 이 캠페인은 검증된 핀을 포함하지 않습니다.
- **고대 정치 지형**: 그 시대 연대 및 국경선이 확정되지 않아 비활성화합니다. *문명*의 영토색 지도처럼 그리면 확정적 지리로 오해할 수 있습니다.

## 핵심 지리 연결

- 그랄 → 브엘세바: 이삭 이야기의 이동/우물 갈등. 절대 거리나 고대 도로 미상.
- 브엘세바 → 벧엘 → 하란: 야곱의 도피 서사 이동 순서; 직선 거리나 정확한 발자취가 아님.
- 하란/밧단아람 → 길르앗 → 마하나임 → 얍복 → 숙곳 → 세겜 → 벧엘 → 에브랏 → 헤브론: 출현 순서이자 복수 에피소드 참조. 반드시 실제 길을 지났다고 주장하는 **역사 경로 데이터가 아님**.
- 세일/에돔: 에서의 가계와 후대 이스라엘·에돔 관계를 비교하되, 족장 시대의 에돔 국경을 소급하지 않습니다.

## 브니엘 고고학 경고

브니엘/브누엘의 현대 후보지는 제안되어 있으나 정확한 위치는 확정되지 않았습니다. 지도 UI는 단일 고정 핀을 사용하지 않고 '연구상 후보지 있음' 설명과 근거를 표시합니다. 출처 `SRC-BIBLEGATEWAY-PENUEL`.

## 실존 도시와 본문 사건의 증거를 분리

세겜/텔 발라타 고대 도시 연구가 있다는 것과 창 34장의 구체적인 사건이 외부 자료로 입증되었다는 것은 다릅니다. 같은 원칙을 그랄·브엘세바·하란에도 적용합니다.

## 지도 데이터 렌더 상태

`confirmed_ancient_place` ≠ `scriptural_person_at_that_place_verified`; 정확한 고고학 후보 위치가 공개 승인되기 전 `coordinatePin=null`. 단계 시작점/종료점 구분은 `placeIds`·`episodeId`와 지도 설명 카드로 대신합니다.
