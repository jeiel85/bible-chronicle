# 인물 관계 및 에돔 계보 표현

## 가문 관계 중심

- 이삭 + 리브가 → 에서, 야곱 (창 25장과 연동).
- 라반 → 레아, 라헬 (창 29장).
- 야곱 + 레아 → 르우벤, 시므온, 레위, 유다, 잇사갈, 스불론, 디나 (창 29–30장).
- 야곱 + 라헬 → 요셉, 베냐민 (창 30장, 35장).
- 야곱 + 빌하 → 단, 납달리 (창 30장).
- 야곱 + 실바 → 갓, 아셀 (창 30장).
- 에서 가문 및 세일/호리 씨족 → 에돔의 족장·왕 목록 (창 36장).

## 모델 구현

관계 테이블에 `person_id`, `parent_id`, `partner_id`, `relationship_basis_passage`, `translation_name_variant`, `editorial_review`를 사용합니다. 가계 및 관계는 사용자가 바꿀 수 없습니다. 이름이 동일한 서로 다른 인물(세겜 인물/세겜 도시 등)은 네임스페이스를 구분합니다.

## 주의 깊은 변이

창 26:34, 28:9, 36:2–3의 에서 아내 이름 목록은 서로 차이가 있습니다. 임의로 동일시하거나 이름을 하나로 합치지 말고 **본문별 명단과 이견 안내**를 함께 표시합니다. `SRC-USCCB-GEN-36-EDITORIAL` 확인.

‘에서=에돔’은 성경 문학의 민족 기원 서술이며 창 36장의 왕 명단을 무비판적으로 족장 시대의 검증된 왕조 연표로 제공해서는 안 됩니다.
