# 실행 화면·상호작용 계약

## 모바일 세로 9:16

사건 아트 30–40% 화면 + 연대기 제목 + 본문 요약 카드 → 하단 탭 [이야기, 위치, 인물, 성경, 학습]. 스크롤형 세로 배치, 접을 수 있는 텍스트/키보드 접근성.

## 모바일 가로·태블릿 16:9 / 4:3

좌측 지도(연대기 진행 경로·불확실성 표시), 우측 사건 카드와 미디어, 하단 선택지. 가로 전환 시 영상이 아닌 **UI 상태만** 재배치하고 진행 상태는 보존.

## PC

키보드: 좌우 화살표(이전/다음 사건), 1~4(탐색 선택), Esc(패널 닫기), Tab/Enter(포커스 선택). 사건 간 이동은 정해진 순서로만 진행. 교사 모드에는 주해 탭/자료 출처 모음/민감 장면 표시 토글 제공.

## 선택의 한계

개별 사건의 '다른 결말' 존재 금지. 선택은 `selectedPerspective`, `visitedEvidence`, `visitedAtlas`, `quizAnswered`, `readingNote` 같은 학습 상태에만 영향. 나중에 재접속해도 같은 사건 결과 ID로 수렴합니다.

## 장별 UX 예시

- 창 26: 우물 이름 카드를 올바른 순서로 정렬하되 정렬 실수로 원래 이야기가 달라지지 않음.
- 창 28: 벧엘의 꿈을 상징적 그림으로 보고 '실제 장소 확정되지 않음' 근거 카드를 열기.
- 창 30: 열두 아들 이름을 가계도에 연결하는 학습 퀴즈(가족 관계를 편집하는 게임 아님).
- 창 32: 얍복과 브니엘의 관계 탐색. 역사적 위치 후보는 확정 좌표로 단정하지 않음.
- 창 34: 경고/연령별 안내 + 본문 카드 + 피해자 관점 안전한 질의. 보복 선택지 금지.
- 창 36: 계보도와 지역 요약 카드; '여로보암 시대의 에돔' 등 후대 자료 연결은 별도 레이어.
