## 국가 경영처럼 보이지만 결과를 바꾸지 않는 기능
- 41장의 풍년/흉년: 성경이 묘사한 수치(7/7, 1/5)를 읽어내는 **자료 분석 교육 퍼즐**. 저장 비율 조작으로 정경의 기근을 막는 게임 아님.
- 47장의 식량 분배: 독자가 어떤 계층이 영향을 받는지 '관찰 카드'로 선택. 사람을 먹이거나 토지의 왕실 귀속을 바꾸지 않음.
- 48장의 교차 축복: '누가 오른손 축복을 받았는지' 관찰할 수 있는 교육용 상호작용. 다른 축복 분기 금지.
- 49장의 지파 축복: 시가서·예언적 표현은 문학 카드로 표시. 영토 색칠을 선택해 성경의 역사 전개를 바꾸지 않음.

## 시각 제작
- 한 사건 16:9·9:16·4:3 버전 별도 구성, 고해상도 원본과 대체 텍스트 준비.
- 본 프로젝트에 포함된 PNG/JPG 일러스트는 **0개**. 현재 파일은 제작 명세만 존재.
- 고유한 상용 게임 아트/UI를 복제하지 않고 대형 이벤트 카드의 일반적 사용성 패턴만 차용.
