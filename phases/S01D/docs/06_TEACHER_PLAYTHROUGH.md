# 교사용 시연 시나리오 — 인물 체험·관찰·자료 비교

## 1) 창 37–38, 35분 / 중등 이상
1. 관찰자 시점 `ep-gen-116~120`: 가족 갈등에서 요셉이 팔려가기까지 장절 범위를 읽는다.
2. 지도: 가나안·세겜·도단·애굽 위치의 **상대적 개념**을 확인한다. '이것이 정확한 요셉의 길'이라는 표현 금지.
3. 이어서 `ep-gen-121~125`: 유다·다말의 이야기를 아동용이라면 교사가 요약하며, 성인 모드에서는 본문 읽기를 우선한다.
4. 질문: '유다는 어떤 책임을 인정했는가?' '요셉 이야기 중간에 유다 이야기를 왜 배치했을까?' 둘째는 해석 질문이고 정답 1개 강요하지 않음.
5. 체크: 꿈의 의미에 대한 신학 해석과 사건 외부 증거를 분리.

## 2) 창 41·47 경제 데이터 / 청소년 이상 / 30분
1. 41장 바로의 7+7년을 읽고 누적 곡식 저장량의 비율을 계산하는 연습 진행.
2. 예를 들어 **가상의 수확량 100단위**를 넣어 1/5은 20단위로 보여준다. 가상 입력값임을 표시하고, 100단위 수확량을 역사적 실제 기록으로 제시하지 않는다.
3. 47장 후반의 흉년·토지 제도와 비교, 41장 비축 정책과 47장 토지 제도를 같은 규정으로 합치지 않는다.
4. 질문: '어떤 사람들에게 이 제도가 다르게 영향을 주었을까?' 성경 본문이 설명하지 않은 이집트인 마음을 창작 사실화 금지.

## 3) 창 42–45 인물 관계 / 전 연령의 비노골적 편집판
형제들의 첫 방문→베냐민 동반→유다의 변론→요셉의 정체 공개를 4막 고정 서사로 읽는다. 방문한 교사는 본문과 감정 추론을 별도 색으로 표시하고 모든 선택지는 관찰·자료 확인으로만 작동하는지 테스트한다.

## 4) 창 46–50 계보·이주·마무리
고센 지역 비교 카드→야곱의 두 손 축복→열두 아들의 시적 축복→두 장례 사건→출애굽기 연결 잠금까지 순서대로 검토한다. `handoff-exo-001`은 다음 패키지 이전에 이동 불가.
